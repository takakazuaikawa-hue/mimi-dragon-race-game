# 画像差し込みガイド（一枚絵CG・立ち絵ポートレート）

このフォルダに画像を置くと、ゲーム内のプレースホルダ枠へ**自動で表示**されます。
ファイルが無い枠は、これまで通り「キャラ色＋象徴アイコン」のプレースホルダのまま表示されます（壊れた画像アイコンは出ません）。

コードは指定パスの画像を読み込み、**成功したら表示／失敗したらプレースホルダにフォールバック**します。
画像を用意したら、下記のファイル名でこのフォルダに置くだけで反映されます。

## 一枚絵CG（ストーリー各話）

| ファイル | 話 | 登場キャラ |
|---|---|---|
| `images/story/1.png`  | 第1話 | サケ・ウダダ |
| `images/story/2.png`  | 第2話 | ミズ・アオラ |
| `images/story/3.png`  | 第3話 | スミカ・ラグナ |
| `images/story/4.png`  | 第4話 | マクラ・クラウン・バズーカー |
| `images/story/5.png`  | 第5話 | セレスティア・ブラックメテオ |
| `images/story/ED.png` | エンディング | 全員 |

推奨：横長（16:9 付近、例 800×450 以上）。各話の「シーン」説明はストーリー画面のキャプションを参照。

|---|---|

推奨：正方形に近い顔まわり（例 400×400）。相談画面の丸/角枠に `object-fit: cover` で収まります。

## 注意

- 形式は **PNG**（透過可）を想定。ファイル名は小文字・拡張子 `.png`。
- 大きすぎる画像は読み込みが重くなるため、適度に圧縮してください。
- 立ち絵・一枚絵のキャラ設定は仕様書 31〜33 を参照（サケ＝竜王女、ミズ＝青髪眼鏡エコノミスト 等）。
