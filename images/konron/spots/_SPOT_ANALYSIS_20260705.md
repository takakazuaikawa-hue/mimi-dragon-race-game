# 崑崙島 spot 解析メモ 2026-07-05

## 現状

- `spots` には市街・港・レース場・グルメ・ショップ・リゾート系の写真が厚く揃っている。
- `js/ui_konron_map.js` では「奥地・霧の彼方」に `dadake` / `susufuka` / `rondo` / `gwaruga` / `kyokai` の5スポットが既に定義されていた。
- ただしこの5スポットだけ `photo` が無く、地図北側の荒い溶岩地帯・霧の奥・島の禁足感が写真として弱かった。

## 追加方針

今回の追加は、街のにぎわいではなく「崑崙島の奥行き」を増やす方向に寄せた。

- `dadake.webp`: 市街と火山の間にある霧の古村。観光地図には載るが近づきすぎない場所。
- `susufuka.webp`: 火山内部へ続く黒い溶岩回廊。熱・硫黄・危険な美しさ。
- `rondo.webp`: ダコン湖近くの沈んだ祭祀宮。竜と人の古い契約の気配。
- `gwaruga.webp`: 北岸の荒岩海岸。道が無く、波と崖だけがある自然の境界。
- `kyokai.webp`: 表の観光島と霧の奥を分ける石門。禁足地の入口感。

## 今後の候補

- 奥地スポットにはグルメ写真を追加しないほうがよい。生活・観光ではなく、伝承と地形の役割が強い。
- 次に増やすなら「竜舎林・ダコン湖」側の水辺/森の写真を1〜2枚追加すると、奥地とスカウト導線がつながる。
- 市街側は既に十分に厚いので、次の増加は `falls` / `sanctum` / `okuchi` 優先がよい。
