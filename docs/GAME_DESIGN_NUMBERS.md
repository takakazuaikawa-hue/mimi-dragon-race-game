# 数値と報酬の設計 — 聖龍爆走録ミミ

ゲームデザイン上の「数値の憲法」。新しい数値・報酬・表示を足すときは必ずここに従う。
（参考：桜井政博「ゲーム作るには」の**リスクとリターン**／**目の前に吊られたごほうび**、
F2P経済設計の定石**1通貨1役割**・**蛇口と排水口**・**ゴールグラデーション効果**）

## 1. 通貨マップ（1通貨1役割・一方向の流れ）

```
　🪙 コイン ──(賭けて勝つ)──▶ 🏦 総資産（最高記録・下がらない）──▶ 🔓 解放
　 │ 蛇口: 配当/連勝/注目/図鑑/ログボ/無心        │
　 │ 排水口: 賭金/モール衣装/生活資産購入          ├─ 📜 物語（5話+ED）
　 └ ただの財布。減っても進行は戻らない            ├─ 🌱 暮らしP → くらしツリー
                                                  ├─ 🏅 ランク（出走/勝利でも進む）→ 新レース
　🎫 メダル・🧵かけら＝モール探検**専用**          └─ 👗 衣装解放（assets条件）
　💗 視聴者/いいね＝**飾り**（勝負に無関係）
　📖 フォロワー（読者）＝**記録のミラー**：完走・単勝・紀行を書いた数だけで増える（名声・ランク・総資産は足さない）。
　　 毎日の印税（ログボの一部）だけに掛かる＝「やったことが記録される→読者が増える→お金になる」（2026-11-12 決裁）
```

**鉄則**
- 通貨を増やさない。新報酬は必ず既存6種（コイン/総資産/暮らしP/ランク/メダル系/衣装）のどれかに落とす。
- コインは「挑戦の弾」、総資産は「人生の高さ」。**負けても物語が戻らない**構造は本作の心臓（spec#30）。
- 飾りの数字（視聴者等）に意味を持たせない。持たせたくなったら衣装かメダルに変換する。

## 2. 目標スタック（常に3階建てで見せる）

| 層 | 目標 | 見せ場 |
|---|---|---|
| 短期（1レース） | 配当・連勝・ミッション | 結果画面の **📦今回の獲得** |
| 中期（セッション） | 次のランク解放・次の物語（総資産しきい値） | ホーム📌ピン・結果画面🎯次の目標 |
| 長期（作品） | 衣装36種コンプ・ED（総資産1兆） | モール所持数・物語画面 |

**ゴールグラデーション**：「あと◯◯」表記を優先（残額・残戦数）。達成率%より残量が人を動かす。

## 3. 報酬の見せ方（目の前に吊るす・まとめて返す）

- **レース結果＝一括の答え合わせ**。配当だけでなく、総資産Δ・暮らしPΔ・ランクUP・物語解放・
  ミッション達成を **📦今回の獲得** に1枚で明示（実装済み: `c.gainLedger` → `.rs-ledger`）。
  「気づいたら増えていた」を禁止。増えた瞬間に名前を付けて見せる。
- 額の大きい順に並べ、色分け＝🪙金（コイン系）/🌱翠（成長系）/📜帯（解放系）。
- 演出の長さは報酬の大きさに比例（tier別紙吹雪は実装済み）。小さい報酬に長い演出を付けない。

## 4. リスクとリターンの明示

- 賭け確認＝「賭金→想定払戻」を常に1画面で対にする（実装済み: 払戻ボックス）。
- 新要素を足すときは「何を失い得るか／何が増え得るか」を着手前に1行で書けること。
  書けないならゲーム性ではなく演出（飾り）に分類する。

## 5. 数値インフレの段差

- 総資産レベルは 1万→10万→1000万→10億→1兆（×10〜×100の段差）＝「桁が変わる喜び」を演出。
- モール価格は ¥1,500〜¥120,000 に圧縮（コイン感覚の学習用）。衣装は性能を持たないので
  価格＝「ご褒美の自己表現コスト」。レース経済とは独立に調整してよい。

## 6. オンボーディング（説明は隠す・初見が分かる）

- 常設の説明文は1行まで。詳細は **？ボタン → モーダル**（実装済み: `showInfoPopup`/`showMoneyMap`）。
- チュートリアル（予想入門）は**アコーディオン＋🆕/✓既読バッジ**（実装済み: `state.player.tutSeen`）。
  初回だけ自動で出す系（初レースほか）は flags を維持。2回目以降は自発アクセスのみ。
- 新機能を足したら：①既定で閉じた説明 ②🆕バッジ ③？導線 の3点セットを必ず付ける。

## 7. 画面フレーム（PC）

- **全画面共通で幅470pxの縦型フレーム固定**（`@media min-width:700px`）。
  キャラ立ち位置・UI座標がPC/スマホで完全一致＝デザインターゲットは常に1つ。
  左右の余白はライブ背景/世界観背景が額縁として機能。タイトル画面のみ全幅（一枚絵）。

## 9. ランク設計（進行の心臓・2026-07-18確定）

ランク＝**経済の「時代」**（賭け上限が跳ね、新レースと市場の高度化が解禁される中期目標の主役）。
昇格は**3本レールのOR**（`RANK_UNLOCK`・判定=state.js checkRankProgression）：

| 目標R | ①実力=R(n-1)帯で的中 | ②皆勤=同・完走(保険) | ③大勝=所持コイン(近道) |
|---|---|---|---|
| 2 | 2回 | 5戦 | 2,000 |
| 3 | 4回 | 10戦 | 1万 |
| 4 | 7回 | 17戦 | 10万 |
| 5 | 12回 | 30戦 | 1,000万 |
| 6 | 20回 | 50戦 | 1億 |
| 7 | 30回 | 75戦 | 5億 |

※2026-07-30 ③の上位を「頂＝10億」の世界へ圧縮（旧 R6=10億/R7=1兆・ユーザー決裁）。①②は不変＝
昇格ペース（実測125〜187戦でR7）は変わらない。正本＝docs/ENDGAME_ECONOMY_REDESIGN.md。

**思想**
- ①実力（式別不問の的中）が昇格の“主役”＝腕前の証明。`hitsByRank` に帯別で記録。
- ②皆勤は①の約2.5倍＝平均的中率(45%前後)なら①が先に発火し、不運な人だけを静かに救う
  保険（「負けても物語が戻らない」spec#30）。旧値3/3/5/5/7/7は上位ほど実質唯一の近道で
  昇格が消化試合化していた（累計30戦≒1時間でR7）のを是正。
- ③大勝＝各値「前ランクの上限賭金×10倍的中1発」。“次の時代の元手を自力で作った”証明。
  所持金基準なので散財すると遠のくが、それは「高い舞台には元手が要る」賭博の道理として意図的。
- 安全に複勝を刻む人は早く上がるが儲からず、勝負師は遅くとも富んで上がる＝プレイスタイルの両立。

**ペース目標（設計値・実測ではない）**：平均的中で累計約165戦・全敗でも約187戦でR7。
1戦約2分＝レースだけで6〜7時間、島時間込みで**メイン10〜15時間級**（コンプ20〜30時間）。

**ED しきい値＝総資産10億（2026-07-30・ユーザー決裁で1兆から圧縮）**：コード`STORY_UNLOCK_AT.ED`=10億が正。
実測でR5帯の本命は期待値+29%＝1億→10億は複利15〜30レースであり、1兆は本命党に永遠に届かない壁だった。
10億＝「最後のイベントレース（神眼レース）」の解放額として設計（正本=docs/ENDGAME_ECONOMY_REDESIGN.md）。
神眼レース実装（M3）までは従来どおり10億でEDの金額パスが開く。旧記載の1兆（2026-07-18決裁）はこれで上書き。

## 10. 序盤の財布（2026-11-13・ユーザーから一任されて決定）

測る道具＝`node tools/sim_early_wallet.mjs <url> [人数] [戦数] [1日の戦数] [服の値段を仮に替える]`
（本物の式をブラウザの中で回す。画面は描かない。賭け方5通り。レースはゲームが薦めるとおりに選ぶ）。
★最初の測定は「はじめの3戦は同じレース」で走らせていて、図鑑のごほうびの時期が実際より遅く出た（服1,500が5戦めに見えた）。
実際の画面での通しと食い違ったので、薦め方を実物に合わせて測り直した。**測るときは、実際の画面の通しと1回は突き合わせること。**

**前提になっている事実（数字は動かしていない）**
- ランク1は賭金の上限が100。ランク2（5戦完走か2的中）で1,000に上がる。
- 1番人気の単勝の勝率は 16〜27%＝賭けるほど財布は減る。空腹は1戦で25進み、食事代は1戦あたり約35。
- だから「1,000 から自分の賭けで 2,000 に届く」ことは、ランク1のあいだはほぼ起きない。
- 無心の額は暮らしレベルの表（Lv1 300／Lv2 1,000／Lv3 5,000／Lv4 30,000…）。新しい竜を見るだけで暮らしレベルが上がるので、
  表のままだと3戦めの無心がもう約5,400〜5,600（ランク1の最大の賭け金 100〜300 の25倍以上）。→ 下の「無心の額の上限」。

**決めたこと**
| 件 | 決め | 理由 |
|---|---|---|
| 最初の服（ブニクロ普段着） | **2,000 → 1,500** | 2,000 は自分の所持金ではほぼ届かず、届く道は「破産→無心」だけ（無心の直後に買えた人：慎重93%・2割賭け97%・最大90%。届く戦は最大7／2割賭け21／慎重24＝慎重な人ほど遅い）。1,500 は、1戦めの注目ボーナス（+300）と2戦めの図鑑25%（+500）で、勝ち負けに関係なく全員が2戦のあとに届く（無心経由0%）。第2話の条件（3戦以上）はそのまま。1,700〜1,800 は「序盤に当てた人だけ」になるので採らない |
| 無心の額 | **表はそのまま。上限を足す＝いまの最大の賭け金（ランクの上限×暮らしレベルの倍率）の5回ぶんまで。下限300**（`assets_engine.js RESCUE_MAX_BETS`・2026-11-13 に改訂） | はじめは「そのまま」と決めたが、Codex の2回めの通し試験で「全財産1,500で服を買った直後に、無心で 5,456 が出て、奮発が霞む」と出た。額そのものが、ランク1の賭け金（100）に対して大きすぎる。上限が効くのは、暮らしレベルがランクより先に進んでいる序盤だけ：ランク1＝Lv1 300／Lv2 750／Lv3 1,000／Lv4 1,500。ランク2＝Lv3 5,000（表のまま）／Lv4 15,000。ランク3＝Lv4 30,000・Lv5 100,000（表のまま）。5回ぶんあれば、食べて走って立て直せる。暮らしの画面と無心の確認窓に出す額も、この実額にそろえた |
| 無心できる条件 | **広げる**（コイン0に加えて、空腹で走れず・ごはん代に足りず・おごりも無いとき） | この状態は無心も出ず、日が替わるまで何もできなかった（計測で20人×30戦に4〜11回）。額と計算は同じ |
| 借金（自力分3万）の見せ方 | **最後の3,000は、単勝で1勝するまで残る** | 0勝のまま5戦めに0になっていた。完済の祝い（資産の開示）は第3話＝初勝利のあとなので、数字だけ先に消えていた。関門・資産の計算は不変 |

**変えるときの決まり**
- 最初の服の値段は `js/data_assets.js` の1か所（`buniqroPrice()`＝モールが開く額も兼ねる）。動かす前後で上の道具を回し、
  「無心の直後に買えた人」と「服に届く戦」を比べること。
- 無心の額・暮らしレベルの表・賭金の上限を動かすと、ここの前提が全部変わる。動かしたら測り直す。
- 無心の上限（`RESCUE_MAX_BETS`）を動かすときは、「無心のあと、次の無心までに何戦走れるか」と「服に届く戦」を上の道具で見ること。
  上限を外した場合との比較は、道具の第6引数に `nocap`（例：`node tools/sim_early_wallet.mjs <url> 30 30 8 0 nocap`）。
- 上限を入れたときの測定（30人×30戦・上限あり／なし）：**無心の回数は変わらない**（中央：慎重1／1・2割賭け2／2・強気3／3・最大12／12）。
  変わるのは、ランク2に上がる前（4〜5戦め）に破産した人の受け取る額（1,000／5,456）と、そのあと数戦の財布
  （5戦後の所持の中央：2割賭け 700／4,256・強気 600／3,256・最大 800／5,262）。10戦後には差が縮む（慎重 5,142／5,206）。
  ＝貧乏な時期が数戦のびるだけで、行き止まりは増えない。服に届く戦（3戦めの頭）・ランク2の戦（5戦め）は同じ。
