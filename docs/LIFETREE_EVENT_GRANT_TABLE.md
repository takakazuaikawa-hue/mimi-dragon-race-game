  | cost | c1 | c2 | c3 | c4 | c5以上 |

### この配分にした理由
- **新しいフラグを1つも増やさない**：22件すべて既存のイベント／フラグに相乗りする。
- **貧しい時期に9件を集中**（#1〜#9）＝「布団で寝られた」「靴下に穴がない」の実感が、
  いちばん効くのが序盤だから。終盤は購入が主役でよい。
- **枝が偏らない**：食5／住4／装い3／移動3／遊び4／格3。
- **シンクへの影響は 22/200＝11%**。コイン消費先の大半（178件）は残る。

## 実装するもの（承認後）
1. 授与カットイン：全画面フラッシュ 0.9秒・タップで即閉じ・進行のモーダルとは別の軽い型。
2. ツリー画面の全ノードに入手ヒント（「章の出来事で」「食べ歩き◯品で」「🪙購入」）。
3. 帯に未達なら保留し、届いた時点で授かる（順序が資産を追い越さない）。
4. 暮らしレベルアップの既存カットインは簡素化（画面へ飛ばさない・正本 D3）。
