# 崑崙島スポット候補バックログ（フレーバーテキスト由来）

> **目的**：暮らし／食事などの**フレーバーテキストに登場する場所**を観光マップのスポット候補として拾い出した台帳。
> 後で「解放順序・条件」を設計するときに、ここから選んで `KONRON_SPOTS` に正式追加する。
>
> **ステータス**：これは**候補リスト（未実装）**。画像も未生成。`tier(仮)` は目安で、**解放順序・条件は今後設計するため未確定（TBD）**。
>
> 作法（既存ルール厳守）：
> - 崑崙＝**明るい熱帯火山リゾート島**。画像は暖色・椰子・緑の火山・実写。**人物は匿名のシルエット/後ろ姿**（“場所が主役”・[[home-tiktok-live]]のVN立ち絵と衝突させない）。
> - スポットは**表示専用メタ**。レース数値・着順・配当・経済には一切干渉しない（[[race-math-immutable]]）。
> - 既存スポットと重複させない（現行 `KONRON_SPOTS` = 34件）。

## 実装のしかた（後で1件ずつ）
1. `images/konron/spots/<slug>.webp`（景色）＋必要なら `<slug>_gourmet.webp`（グルメ）を生成（熱帯ロック＋シルエット）。
2. `js/ui_konron_map.js` の `KONRON_SPOTS` に1行追加：`<slug>: { name, cat, tier, time, photo, (gourmet), shoot, line }`。
3. 同ファイルの `KONRON_AREAS` の該当エリア `spots:[]` に slug を追加。
4. （任意）`js/konron_content.js` の `KONRON_CONTENT` に 見どころ/名物/豆知識 を追加。
5. `index.html` の `?v=` をbump、git plumbingでデプロイ、ライブ確認。
6. **解放条件**：現状は総資産tier（`KM_TIER_AT=[0,3000,1e6,1e8]`）。今後の解放順序システムができたら、その条件に差し替える（下表の「解放(TBD)」列）。
