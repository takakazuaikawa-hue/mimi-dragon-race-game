## 3. 物語の全面再執筆（R3・ユーザー承認制）

**方式＝聖龍日報の記事体**（物語画面は既に新聞デザイン＝見た目と中身を一致させる）：
- **大見出し**（新規・記事らしい芸）＋**リード**＝現行の一文「件。」スタイルを2〜3行に凝縮して継承（ブランドの芸は殺さない）
- **本文**＝3〜6段落の場面構成（会話引用込み・ミミの一人称手記が新聞に載っている体＝発行元「ミミ通信社」と整合）
- **談話**＝章の顧問の一言（各キャラの声：サケ=まず食え系の短い命令／ミズ=「〜のであるわ、あはん」／スミカ=丁寧語で殴る／マクラ=配信テンション／セレスティア=世間話のような天災）
- データ形：STORY_CHAPTERS に `lead` フィールド追加・`body` は `\n` 段落（.news-text は pre-line 済み＝表示改修は最小）
- **B4解消**：第3話にポロの気配（帳簿の隅の泣き声）・第4話に配信への映り込みを本文で回収
- **B3解消**：ED後に「特別號・クリア後特集面」を追加（グルメレース/タワー/コレクションへの送り出し記事）
- 手順：第1話サンプル→ユーザー承認→全章執筆→章導入VN(DLG.chapterIntro)との整合確認
