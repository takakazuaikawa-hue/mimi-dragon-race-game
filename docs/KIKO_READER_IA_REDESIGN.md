## 1. 『紀行』リーダー（新画面 `kiko` — 読み物ハブ）

**紀行の中身＝プレイヤーの実績そのもの**。既存データに読み物テキストは全部ある
（食＝`meals.js` の実食コメント/note・竜＝`data_dragon_lore.js`・観光＝`konron_content.js`・
小イベント＝`data_story_events.js`）。新規執筆はほぼ不要＝**組版だけで本になる**。

```
📖 ドラゴンレース紀行（表紙）
   著者 ミミ・パホパホ ／ 第◯巻（章進行連動） ／ 発行部数（累計売上から換算） ／ 充実度◯%
├─ 巻頭「きょうの一筆」 … 直近の実績1件を紀行の一人称で1枚に自動整形（毎日変わる）
├─ 🐲 竜の章    → 図鑑（既存 renderCollection）
├─ 🍽 食の章    → みみしんぼ（既存 renderMeals）
├─ 🏝 島の章    → 崑崙ガイドブック（既存 konron_guide）
├─ 📷 写真の章  → フォトコレクション（既存 konron_gallery）
├─ ✨ 人の章    → 物語の小イベント集（既存）
├─ 🎁 持ち物の章 → 生活資産コレクション（既存 renderLifeCollection）
└─ 🏆 奥付      → 達成度（collectionScoreParts）＋売上のあゆみ＝「この本がいくら稼いだか」
```
- 目次の各章に**達成率バー**（例 🍽 食の章 12/44）＝収集意欲の一望。
- 「きょうの売上」モーダルに **「📖 紀行を読む」** ボタン＝売上→本文の導線が閉じる。
- 表示専用・レース数値不変。充実度が上がる＝売上が上がる、が**見て分かる**。

## 2. メニュー整理（紀行を軸に「する／読む」を分ける）

```
🌳 暮らし（「する」に痩せる：7→5項目）        📖 紀行（「読む」の新ハブ）
├─ 🌱 くらしツリー                           ├─ （上記の章 全部）
├─ 🎫 習い事                                 └─ 🏆 奥付（コレクション得点を統合＝
├─ 🏦 島の経済（＋島づくり）                        終章後の「？？？」もここに）
├─ 💬 相談（顧問）
├─ 📖 物語（=ドキュメンタリー『ミミ、爆走中。』）
└─ 📖 ドラゴンレース紀行 → 紀行リーダーへ
```
- **物語は紀行に入れない**：物語＝外部メディアの密着ドキュメンタリー／紀行＝ミミの著書。
  別メディアなのが設定の面白さ（自分で書く本と、撮られる番組）。
- 図鑑は龍舎にも残す（竜の世話の文脈）。**読む導線＝紀行／育てる導線＝龍舎**の2口はOK。
  それ以外の移動元（生活資産コレクション・コレクション得点）は暮らしから**移動**（重複させない）。
- 5タブ自体は触らない（固定5タブの設計=HOME_COMMERCIAL_REDESIGNを壊さない）。

# §4 新設計（決裁v2準拠）— 紀行ブログ ＋ 5タブ全面再編

## 4-1. 紀行＝ミミのWEB連載ブログ（新画面 `kiko`）

**メディアの三面**（設定の芯）：
- 📖 **紀行ブログ** ＝ ミミが**書く**側（自分のメディア・収入源）
- 🎬 ドキュメンタリー『ミミ、爆走中。』 ＝ ミミが**撮られる**側（物語画面・既存）
- 📱 SNS ＝ ミミの周りを**流れる**側（既存）

**画面構成（ブログUI・スマホ縦）**：
```
┌──────────────────────────┐
│ 📖 ドラゴンレース紀行  ← ブログロゴ（手書き風・かわいく）│
│ by ミミ🐰 ｜ 読者 12,400人 ｜ 累計PV（累計売上連動）    │
├──────────────────────────┤
│ ✍️ 今日の更新（1日1本・実績から自動生成の短い記事）      │
│ ｢屋台の塩パスタたべた！麺、太め。汗かいた竜に効くやつ🍝｣ │
├──────────────────────────┤
│ カテゴリ（チップ・達成率つき・タップで既存画面へ）        │
│ #たべある記 12/44  #竜ずかん 24/52  #島さんぽ 8/40      │
│ #フォト日記 16/20  #ひとびと 5/18   #おかいもの 9/16    │
├──────────────────────────┤
│ 📈 ブログのあゆみ（充実度＝売上の理由が見える・実績集約）  │
└──────────────────────────┘
```
- トーン＝**ノリがよくて健康的な明るさ・かわいい**。！と絵文字多め・食レポ全力・自虐は軽く。
- 見た目＝**画面スコープCSSで明るいメディア面に切り替える**（前例：物語画面のダーク×ピンク番組UI・
  暮らしのkt-page紙面）。ダークな島世界の中で「ブログを開いた」感を出す。
- 「今日の更新」＝直近の実績1件（食べた/出会った/撮った/買った/勝った）をブログ文体1枚に自動整形。
  文はデータ流用（meals.react/note・dragon_lore・konron_content）＋ブログ的な枕/締めテンプレ。
- 読者数＝フォロワー（既存式）・累計PV＝累計売上から換算。「きょうの売上」モーダルに「📖 ブログを見る」。
- コレクション得点（終章後の🏆）は「ブログのあゆみ」に統合＝紀行が実績のハブになる。
