# 本編の神眼レース「最後の一面」

## 第五話から公示へ

第五話を読んだミミは、決戦に出る七頭と実際に仲よくなり、物語でポロと出会えば、島祭を開ける。第五話の前に迎えた竜も同じ一頭として数える。第五話以降は編集部の取材便で未加入の決戦竜に会いに行ける。現地でしのびあしと会話を成功させると友好が保存される。新規スカウトごとのメーター22点は廃止した。以前に得た点と `finalReady` は保持する。

入口の条件は「第五話既読、かつ八頭取材済み・準備メーター達成・到達最高資産10億のいずれか」。後二つの資格で入って取材が足りない場合は、会いに行く相手が分かる。公示を確定するには八頭が必要。八頭から直接進んだ場合も、未所持の竜帝の戴冠衣は公示の前に受け取れる。以前の授与が中断していた場合は実際の所持品を確かめて再開する。

## セレスティアとミミの予想

本編の入口は `shingan_festival_ui.js`、開催と会計は `ShinganFestival` が受け持つ。公示では八頭のコース適性と開催ごとのばらつきで着順を先に決め、セレスティアがその一着を告げる。勝者は開催ごとに変わりうる。ミミはコースと各竜の観察、平日または祭日の客の顔ぶれ、公開された一着を読んで窓口と紙面を決める。整備や指名で着順は変わらない。

複勝は二着以内の一頭、ワイドは三着以内の異なる二頭を予想する。単勝のみ、単勝と複勝を扱う一窓口、ワイドも扱う二窓口から開催方法を選ぶ。扱う予想欄を埋めれば発行できる。発行前の収支は、予言で確定した一着を除く二・三着の42通りを想定した範囲で確認できる。

その日の成功には、予言に含まれない読みが少なくとも一件、掲載を受けてその券を買った客に的中し、かつ当日の営業で費用を賄うことが必要である。神眼が告げた一頭を複勝にしただけの場合、販売していない参考欄だけが当たった場合、全的中でも開催が赤字の場合は、それぞれ足りなかった条件が日報に残る。現行の開催では成功号を起点に島の次の季節の営業を引き継ぐ。

## 島の何が営業に効くか

公示時に本編で完成していた六分野のレベルと、八頭の友好・ポロとの出会いを記録する。基本の船・会場・地元客がいるため、小規模な開催から試せる。来場希望者が増えても、船と席に空きがある人数だけが来る。

| 本編の分野 | 当日の受け入れ能力 |
| --- | --- |
| 施設 | 船で来られる人数 |
| レース | 会場の席数 |
| 公共 | 給水などで地元客が滞在できる人数 |
| 竜 | 友好を結んだ竜を見に来る客の見学枠 |
| 商業 | 売場で扱える品数 |
| 産業 | 島から搬入できる品数 |

既刊の『ドラゴンレース紀行』を選ぶと、その号の読者に開催を知らせて島外からの来場希望を増やせる。現地で検証した発見に企画があれば、対応する実施設の当日の使い方を選ぶこともできる。企画書だけの未整備分野には工事実績も追加の枠も生じない。一開催で選べる呼びかけ・企画は合わせて一件。過去に自分で残した一戦の手帖も一件添えられる。

## 当日会計

本編の表示では帳簿1単位を1,000コインとする。各来場者が持参した10,000コインを券、買物、未使用に分ける。1票1,000コインで、実売品は一品1,000コイン、原価500コイン。開催費は単勝窓口と一窓口が24,000コイン、二窓口が38,000コイン。ミミ個人の財布から払う費用はなく、紀行の個人印税や施設の資産評価額も開催収入に加えない。

券種ごとに実売と払戻を清算する。的中票に元本を払い、売上の80%から的中元本を引いて余りがあれば、票の付いた的中組に配る。的中組への投票がゼロならその券種を全額返還する。全員が予言どおりの一着を買えば、単勝の売上はすべて払戻に回り、そこから開催費を出せない。複勝やワイドを買う客が増えたときは、それぞれの窓口の実売と払戻が当日の収支に反映される。

当日の運営収支は **各券種の売上から払戻を引いた合計 ＋ 実売品の粗利 − 開催費**。六分野未整備の平日は、常連20人・地元16人・船の客10人。複勝を扱う一窓口で800コイン残り、二窓口では2,800コイン足りない。同じ島でも祭日には一窓口で4,800コイン不足し、二窓口で6,800コイン残る。来場者数、財布、費用、券種の好みと仕入原価は、この開催に置いた仮定である。

## 島の店・船・競走を季節ごとに再建する

セレスティアが一着を告げ続けても、店が代金を受け取り、船が次の荷を運び、競走を開き続けられるかを季節の帳簿で確かめる。成功号と、それまでに発行した開催の日報の実収支を通算し、正なら現金、負なら島祭の未払として引き継ぐ。単勝への集中で費用が残った日も帳簿に残る。投資した施設は以後の営業を助け、建設費をもう一度収入には計上しない。

各季の前に、平日か祭日か、地元の注文、寄港、雨の日の荷受け、仕入と必要借入が分かる。開催の見込みは未知の上位三頭336通りから計算する。どの着順でも券種全体の売上と払戻総額が同じなら、収支は一点の見込み額になる。窓口と納入先を選んで季を進めると、その期の別の競走と商品の受渡しを実際に清算する。納入先の返事と次の見通しを読んで翌季の契約を替えられる。

| 納入契約 | 商いと島での経験 |
| --- | --- |
| 屋台へ旬の食材 | 地元の予約を前受けして仕入れる。献立を予約表で説明するには、実際に訪れた店で食べ、アヤに対面で返事をした記録（`mealConversation`）が要る。「また食べたい」「別の方が合いそう」「まだ決めない」は同じように本人の経験として扱う。SNSだけの返事は対象外。秋の雨には、調査で確かめた配水経路が荷の引渡しを助ける。 |
| 船で果実酢を届ける | 工房が中身を用意し、島外から新瓶を仕入れる。容器代と船賃を払い、渡せた本数で清算する。封済みの売れ残りは倉庫に残り、次の季に先に納める。確認した潮待ちの印で積込時間を調整でき、紀行の既刊は島外からの注文募集に使える。 |
| 港の戻り瓶を工房へ | 果実酢と空瓶の受渡しを島で確かめると選べる。港の未仕分けの瓶は計8本まで。仕分けと洗浄を行い、配達先から戻った空瓶も次の受取帳へ繰り越す。不足分だけ新瓶を輸入する。 |

買い手の予算には上限がある。前金はその契約の仕入と輸送に充当し、渡せなかった分は売上に入らない。当期の前払に現金が足りなければ差額だけを島祭が借りる。信用枠は残高合計48,000コイン、利息は期中元本の1%を1コイン単位で切り上げる。手元の現金で利息・未払・元本を払う。運転資金が足りない時は、その季の競走を休み、予約品の引渡しに絞って立て直せる。

市場の納品だけに絞った季も、共同荷受所で品を保管し、担当者が伝票を照合する。その費用は営業日一日1,500コイン。春4日・夏4日・秋3日・冬3日の通年14日で21,000コインとなる。仕入・船賃・開催費とは別に季末に請求し、払えずに残った額は未払として次の季へ送る。この金額は再建営業に置いた新しい仮定で、過去の開催や取材便の実費には計上しない。

四季を一巡し、直近四季の事業収支の合計が黒字で、その間に平日と祭日の窓口を実際に開き、未払・借入をすべて払い、次の一窓口の24,000コインを残せば、再建を見届けてエンディングへ進める。足りなければ同じ残高・債務・在庫で翌年も営業する。この帳簿は、予言の下で島の店・運送・競走を継続し、この事業に生じた支払いを返せたことを示す。原典で額の決まっていない全島の過去債務や、将来の景況までを見積もるものではない。

## 発行記録と旧号

現行の新規開催（rules 2）では、各季に実際に使った島の施設・発見・契約、納品・返済・期末残高を保存する。公示後の投資も翌季の契約から使える。復帰時は保存済みの各季の入力で入出金を検算する。季節営業を導入する前のV2（rules 1）で公示した開催は、当時の一日条件のまま発行・エンディング復帰できる。

`player.shingan.festival` に、公示時の島と取材の記録、開催番号、着順抽選のシード、開催を識別する乱数（nonce）、ルール版、下書きの変更番号（revision）を保存する。再読込しても同じ開催が開く。公示後の投資は次の新開催の準備に回る。編集・発行時は開いた時点の開催と変更番号を照合し、発行後は掲載内容、着順と当日の会計を固定する。失敗号は何度でも振り返れる。次の予想を発行するときは別の公示と未知の着順で始める。復帰時は当時のルールと凍結入力から保存結果を検算する。

旧V1の `player.shingan.official` は、海風の固定着順に対する三枚の紙面と当時の成否を残す。検算済みの旧成功号からエンディングへ復帰する場合だけ旧画面を使う。旧失敗号を持つミミは、その号を履歴に残したまま新しいV2開催へ進める。さらに前の同着決戦の既得クリアは元の由来で残す。旧号の収支は当時の単位で読む。

独立した経済ラボは、整備と取材を仮定した比較用の試作で、試作コインと固定の神眼を使う。本編と共有するのは券種ごとの払戻関数。試作のプリセット、財布、発行結果は本編セーブへ移さない。通常の競走・オッズ・馬券には既存の処理を使う。

`tools/check_shingan_festival.cjs` は取材・施設・既刊の読込、予想と収支の反例、旧号照合、中断復帰を検査する。`tools/check_shingan_festival_ui.cjs` は正式入口・保存・発行・復帰を、`tools/check_shingan_official.cjs` は旧方式の互換性を扱う。これらの試験から初見の人間の的中率や一周の長さは推定できない。


## 既存の水番との小さな手入れ

配水小屋を本当に発見した後、棚田の現地で材料代300コインを払い、既存の運び架を水番と直せる。一度限りで、公共の新しい井戸や施設Lvは増えない。個人455→155の財布を支払前に見せ、売上を個人へ戻すこともない。雨の朝市の地元受渡しだけ、営業日ごとに一口を追加する。現在の施設・注文で18→21口、他季の納入数と競走収支は不変。発行済み号・過去期は固定し、次期の確定時のsnapshotで手入れを読む。

補修なしの正規の新規プレイは五季で完済し、営業口座28,784を残して実EDへ到達した。この任意支出は無料の企画書を実績に変えるものでも、クリアの追加ノルマでもない。材料代・改善幅は作品用の設計値として数値正本に記録する。

予約前金の使用先は材料と運送に限定する。前金が仕入と送料を超えた分は引渡しまで預かるため、会場の前払に充当しない。プレビューには受け取る前金と実際の充当額を示し、引渡し時の売上に前金を二重加算しない。
