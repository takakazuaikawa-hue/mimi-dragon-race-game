## 0. 絶対ルール順守（最重要・1ミリも譲らない）

| ルール | 本システムでの扱い |
|---|---|
| ① レース数値（着順・オッズ・配当・抽選/賭け）変更禁止 | **一切触れない。** doom/絶滅メーター・押し戻し量・保護した竜・なつき度は `race_engine`/`odds_engine`/`betting_engine` に**絶対接続しない**。竜は**コスメ・図鑑のみ**（レースには出さない）。 |
| ② mainへのpush＝即デプロイ | 終章は段階実装。壊れない単位でcommit。 |
| ③ CSS/JS変更時は index.html の `?v=` を一括前方更新 | 新ファイル追加・CSS追記のたびに必ず（"今ライブの版数の次"へ。[`CLAUDE.md`](../CLAUDE.md) 参照）。 |
| ④ classicスクリプト構成 | 新ファイルは自己完結モジュール（`mall_dungeon.js`/`poro.js` と同作法）。`<script>`は index.html に列挙。 |

### 終章固有のガードレール（特に注意）
- **絶滅メーターは「実オッズ」ではない別ゲージ**。演出として「答えの竜の単勝が **1.1倍 → 1.0倍** へ近づく文字盤」を見せるが、これは**島の運命を表す飾り**であって、本物の出走表のオッズ・配当には一切反映しない。実レースのオッズ行には絶対に描画しない。
- **唯一オッズに触る例外＝セレスティアの神眼コンサルト（既に実装済）**。`consultCelestia`/`applyCelestiaCollapse`（`ui_render.js`）。総資産1億で解放・**プレイヤーが任意で「聞く」を選んだ時だけ**・**1レースのその竜だけ**オッズ×1.01・**着順は不変**。これは「1着を知ること≠価値を残すこと」を教える意図された設計。終章メーターはこれとは**別物**。
- **最終バトルレースの着順・オッズ・配当は従来の `race_engine` の結果のまま**。勝利は“結果を覆すこと”ではなく**“場が壊れず全員が沸いたこと”**。

**判定の合言葉**：「これはレースの強さ・オッズ・着順・配当を1ミリでも動かすか？」→ Yesなら設計が間違い（神眼の任意例外を除く）。

## 1. 思想の背骨 ―― 予言者 vs 賭場（要約）

詳細は [`PARIMUTUEL_ORACLE_VS_HOUSE.md`](./PARIMUTUEL_ORACLE_VS_HOUSE.md)。終章はこれの劇化である。

- **予言者が1着を確実に告げる** → 全員が単勝Aへ集中 → ハズレ票が消える → 配当が1.0倍へ → 元返し → **賭場破綻**。
- ＝**セレスティアの神眼**が竜の「生き残る順番」を見せ、誰の手にもあった“応え”を**たった一頭の正解へ淘汰**する＝**絶滅**。
- **打開**＝予言者を上回る予言ではない。**「正解が1点に定まらない構造」**を作ること。予言者の射程外＝**2着の高配当・複勝・ワイド・オッズの端の歪み・多様な穴**へ生命（賭け金）を分散させる。全資金の**2〜3割**を単勝Aの外へ逸らせば1.0倍割れを回避できる。
- **皮肉な結論**：賭場を守るのは賢い設計ではなく、**客の射幸心・大穴バイアス（儚い穴を愛する心）**。── これは [[poro-companion]] の **ポロ＝「特別ではなかったと分かっても愛され続ける」** が生きた証拠。淘汰（強い者だけが価値）への最大の反証がポロであり、ミミ自身（明日のご飯代の穴バニー）である。

## 5. 絶滅メーター（綱引き）の設計

すべて表示メタ。**関数は新ファイル `js/epilogue_engine.js` に集約**し、レース系engineからは呼ばない。

```js
// state.player.epilogue（表示メタ／レース数値・コインに非干渉）
epilogue = {
  active:false,    // 第5話再生でtrue
  doom:0,          // 淘汰の前進（レース確定ごと +d）
  push:0,          // 押し戻し量（4活動で増える）。doomを相殺
  doomMax:48,      // doom単独で到達するとソフト失敗（要バランス）
  pushTarget:100,  // これだけ分散しきると最終レース解放
  cycle:0,         // ソフト失敗での仕切り直し回数
  finalReady:false,// net<=0 かつ push>=pushTarget で true → 最終レース解放
  edFlag:false     // 最終レース完走で true → ED
};
```

- **表示メーター（飾り）** ＝ `net = clamp(doom - push, 0, doomMax)` を **「1.1倍 → 1.0倍」の文字盤**で可視化（netが大＝1.0へ／押し戻すほど1.1へ）。**実オッズではない**。
- **解放条件** ＝ `push >= pushTarget` かつ `net <= 0`（淘汰を完全に押し切った）→ `finalReady=true`。ホーム/物語に「最終決戦」導線を点灯。
- **ソフト失敗** ＝ `doom >= doomMax` のまま押し戻せない時：セレスティア「……まだ、淘汰は終わらない」→ `doom` を戻す（`push`は保持）。ゲームオーバーにしない。

```js
function doomTick() {                 // settleRace から呼ぶ（終章中のみ）
  const e = state.player.epilogue;
  if (!e || !e.active || e.edFlag) return;
  e.doom = Math.min(e.doomMax, e.doom + 1);   // d=1（要バランス）
  if (epilogueNet() >= e.doomMax) onDoomReached();
  saveGame();
}
function pushGain(points, reason) {   // 4活動の成果ハンドラから呼ぶ
  const e = state.player.epilogue; if (!e || !e.active || e.finalReady) return;
  e.push += points;
  if (e.push >= e.pushTarget && epilogueNet() <= 0) { e.finalReady = true; onFinalReady(); }
  saveGame();
}
function epilogueNet() { const e = state.player.epilogue; return Math.max(0, e.doom - e.push); }
```

### 押し戻し配点（要バランス・表示専用の意味づけ）
| 活動 | 既存フック | pushGain の意味 |
|---|---|---|
| 🌴 スカウトで**新種を初保護** | `poro.js`（scouted） | 大（穴の母数が増える）。既知再訪＝小 |
| 🏠 **総資産レベルが上がる** | `recomputeAssets` の段階上昇 | 中（島の経済発展） |
| 🛍️ **モールで買い物（購入）** | `buyOutfit` 等 | 小〜中（灯り・賑わい。連続は逓減で作業化防止） |
| 🏅 **的中／連勝／名声の更新** | `settleRace` の進行確定 | 中（守り手予想家の信頼） |

> 配点・doomMax・pushTarget・d は `epilogue_engine.js` 先頭の定数表に置き、後から差し替え可能に（`data_ending.js` と同じ「中身と演出を分離」の思想）。実機の手触りで調整。

## 6. 最終バトルレースの設計

絶滅メーターを押し切ると解放される、**終章のクライマックス**。普通のレースを**演出で祝祭化**するだけ＝レース数値は不変。

- **入口**：`finalReady` 点灯後、ホーム/物語に「⚔️ 最終決戦」。押すと専用前口上 → 既存のレース描画（`renderRaceRun`/`race_canvas.js`）へ。
- **使うレース**：既存のレース（できれば象徴的な大レース）を**そのまま**。`runRace` の結果・オッズ・配当に**触れない**。
- **演出（化粧）**：レース前〜道中に、**積み上げてきたものを次々に紹介**する“走馬灯ショー”を重ねる ── 保護した竜（図鑑/scouted）・総資産と島の発展・着てきた衣装と称号・相棒ポロ・育った村・出会った顧問たち。観客（コメント/歓声）が最高潮へ。
- ★**予想は覆らない**：セレスティアの読み（1着）は当たったまま。だが**単勝の外に複・ワイド・穴の歓声が満ち**、賭場は1.0倍へ張り付かない＝**壊れない**。EDの既存本文「単竜では薄くなりすぎた正解のまわりに、複竜で残る席を探し、ワイド竜でまだ沈んでいない組み合わせを拾い…」を、この瞬間に重ねる。
- **完走で** `edFlag=true` → セレスティア「この賭場、壊れなかったね」→ `Ending.play()`（既存スタッフロール）。
