## 3. 序盤の流れ（服→空っぽ→無心）を遊んだ感想

**到達の改善は成功。コメディとしての着地はまだ弱い。** 2連敗でも「買える」に届いたAは、前回の延々と貯まらない印象から明確に変わった。服の札を押し、買い、普段着でホームに立つ。ここは気持ちよい。[購入後](playtest_shots_20261113/10_A_firstoutfit.jpg)／[普段着と所持0](playtest_shots_20261113/12_A_broke.jpg)。

ただ、「全財産で服を買った」実感は、画面が作るより、こちらが1,600→100を計算して作っている。購入時のミミは「やっぱりこの普段着が一番おちつくな〜」。残り100への驚きも、明日のごはんへの不安も無い。大勝負の770には専用の緊張があるのに、暮らしを変える1,500の支払いには同程度の重みがない。

無心の「ぱほ。。。」「ぱほぱほ。。。」という溜めは、最初は可笑しい。でも、その後の＋5,456と「ありがとう。…次は、当てる。」は、笑いより救済の通知として受け取った。顔のある村人の反応やミミの取り繕いがなく、恥ずかしい失敗が「基準額」を受領する手順になる。**確認窓の「基準額」が、特にゲームの裏側の言葉に聞こえる。**

額についての生の感想は、**かなり大きく感じて、服の奮発が軽くなった**。初期1,000、頑張って届いた服1,500、その直後の5,456。ここで「貧乏から少し上がった」より「破産すると一気に戻せる」が頭に残る。決裁どおり額は据え置きでよいが、ならば大金そのものをミミが驚く笑いにするべきだ。例えば「さっきの服、三着買えるんですけど!?」と慌てる、渡す側が呆れる、といった短い返しがほしい。現在の静かな礼だけでは、この大きさを受け止めきれていない。

Bは少し違う。的中して2,270→770なので、服にほぼ全財産を使った感じはない。次にその770を全額賭けて失ったから無心になった。**同じ「3戦目で無心」でも、Aは服への奮発の後始末、Bは追加の大勝負の後始末だった。** 2通りだけの結果から、全員に同じ感情の流れが起きるとは言えない。

第2話は両方3戦目で公開。服が話を進める条件になっていることは確認できた。ただ、Aは破産・3連敗の賭式の助言・無心案内・新章が重なる。失敗を一つ味わって笑う前に、次に読む内容が積まれる区切りでもあった。

## 4. 画面ごとの辛口批評（重い順。各項目に「どう直すか」）

### 1. 購入・無心：いちばん笑えるはずの財布の変化が、数字で終わる

A2後の服購入とA3後の無心。残高の落差は大きいのに、ミミの反応はどちらも穏当だ。見た目の綺麗な着替え画面はできている。しかし、ド貧困の本人が何をやらかしたのかが薄い。「よかった、次の案内はどれだろう」と流してしまう。ここは序盤の主役の場面にする価値がある。

**どう直すか：** 購入ボタン付近に「支払い後の財布100」を先に出し、購入直後の一言だけ残高に反応させる。無心の「基準額」を生活の言葉へ替え、受領額へのミミと渡す側の短い応酬を付ける。新しい全画面説明は足さない。金額・条件は変えない。

### 2. 物語：読む体験の操作が、会話と朗読カードと本文に分かれる

今回初めて第1・第2話を実際に読んだ。Aの第1話は、チャンネル一覧→話→立ち絵会話を送る→別の朗読カードが残る→×で閉じて本文、という手順になった。「次へ」「スキップ」「▼つづき」「×」「エピソード一覧へ」と、読む対象ごとに操作の意味が替わる。物語の面白さを感じる前に、どの読み方にいるかを処理する。第2話も同じ構造だった。

**どう直すか：** 初回の再生が終わったら、本文か一つの朗読表示に着地させる。本文を読む／演出で再生する、の入口を明示して、同じ話を開くたびに別形式を閉じる手間を減らす。今回は本文自体の全面書き直しより、出口を一つにする方が効く。

### 3. 結果：具体的な返事が良くなった分、隣の雑な短評が目立つ

A6は単勝4着で「あと3頭ぶん」なのに、ミミは「鼻の差」。B3とB5は1着から8着まで全員「終盤に脚が止まった」。全頭が失速すること自体を数値の不具合とは言わないが、これでは勝者がどう勝ったかの説明がない。新しい返事は自分の走りを見てくれるのに、隣の欄は別のゲームの定型文を読んでいる感じがする。

**どう直すか：** 差を確認していない文で「鼻の差」と言い切らない。勝者の短評は、失速していても「粘って先着」など勝った事実を含める。返事・短評・ミミの反応を同じ結果の言葉として整える。計算には手を入れない。

### 4. 食事：行き先は直ったが、選択時には皿の用途が見えない

A4・B4後、空腹0から正しい段へ開いたのはよい。しかし初回は12枚とも「？？？」と価格で、回復量は開かないと分からない。金枠と説明を読めば食べられることは分かる。それでも、走れる状態へ戻す必需品を、まず中身当てで探す感触がある。Bで開いた「ひとり鍋（白菜だけ）」は名前そのものが可笑しいのに、入口ではその面白さも隠れる。

**どう直すか：** 初見の名前を隠す作りを残す場合でも、カードに「おなか＋30」「＋55」等の既存の回復量を出す。初回おごりもカードを選ぶ前に短く知らせる。「知らない料理を試す」と「今すぐ腹を満たす」を同時に判断できるようにする。

### 5. レース：後方の推しは戻ったが、「◂」の意味は一瞬考える

B1のモムは体ごと残り、「◂120m」も読めた。[後方表示](playtest_shots_20261113/18_B1_rear.jpg)。邪魔な追加表示とは感じない。8番手から3着まで上がる過程を追えたので、この修正は続けてほしい。ただ、名札は小さく、隣のセラム等と近い。「先頭までの距離」と初見で即断できる表示ではなく、画面外への方向か、コース上の距離かを一度解釈した。

**どう直すか：** 初めてこの表示になるときだけ「◂＝先頭まで」の短い補助を出す。常時文字を増やさず、自分の名札の距離部分だけ少し明瞭にする。体を残す範囲を広げて他の竜を隠す必要はない。

### 6. 紀行：報酬は分かる。次の本文を読みたくなる誘いが弱い

A6後、＋200人が見えたので、前回より迷わず書いた。本文の外れ券と負け飯の場面、常連の「三枚持っていきな」は読んで楽しい。一方、押す前の取材メモは「まずは、ここへ来た日のことから」。これは準備の説明で、読みたい場面ではない。報酬の表示が良くなった今は、連載の続きを読みたい気持ちをもう一段作れる。

**どう直すか：** 次の取材先の既存の一行を、本文の面白い場面の短い予告へ替える。例えば第1回なら「外れ券を見せると、盛りが増える屋台」程度。＋200の上に新しい説明段落を積まない。過去のあゆみの並びは変えない。
