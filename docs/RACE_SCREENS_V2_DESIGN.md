# 予想画面・レース画面 v2 — 骨組みから（2026-11-26）

前段の `docs/RESEARCH_RACE_VISUAL.md` は「飾りを引く」だけで、骨組み（配置・大きさ・情報の量）を変えなかった。
ユーザー：「びっくりするほど変わってない」「骨組みも二段階高度に。プロの目線で意味のある気持ちのいいものに」。
この文書は、参照先と今の画面の**骨組みの差**から設計し直す。表示のみ（着順・オッズ・配当の計算は不変）。

## 0. 参照（実画面・設計資料で確認済み）
- ウマ娘のレース：絵が画面のほぼ全部。実況は箱なし字幕2行。自分の着順だけ大きく「1/18」。上端に細い GOAL←→START の帯
- F1 中継：**左端に順位の塔（タイミングタワー）を常設**。順位・名前・チームだけ。順位が動いた瞬間だけ短く動く
- JRA トラッキング中継：箱なし。枠色の丸札。タイム・距離は絵の上に縁取りで直接
- TIPSTAR 2025：予想は「冷静」（落ち着き・明快）、レースと的中は「熱狂」。カードの中は大きな数字1つ＋小さな補足
- Racing Post Smart View：1頭1枚。識別（勝負服・番号・名前）左上、オッズ右上の独立した箱、能力は目盛り
- FanDuel のデザインシステム（Sheets）：賭け札は**小さな要約から始まり、押すと全部の確認へ広がる**シート
- ウマ娘 UI 講演：上から固定ヘッダ／サブ／メイン／固定フッタの4ゾーンを守る

## 1. レース画面 v2 ＝「中継の一枚絵」

### 今の骨組み（390×844 で実測）
絵 約50%／その下に実況の箱2つ（約84px）／順位表（4〜8行）／操作の列。**情報が絵の外に縦積み**＝視線が絵と表の間を上下に往復する。

### 決めごと
- 絵の上の文字はすべて**箱なし**で、上下の暗いグラデ（スクリム）の上に置く。読めることはグラデの濃さで担保する
- 記号は**竜の色の丸札**だけ（絵の中の札・塔・自分の竜の表示で同じ）
- 金は「自分の竜」と「的中ライン」だけ
- 動くのは状態が変わった瞬間だけ（順位の入れ替わり・圏内に入った瞬間）。常時光らせない

### 自己批判
| 案 | 批判 | 判定 |
|---|---|---|
| 順位表を絵の左に重ねる（F1式の塔） | 後方の竜が塔に隠れる → 竜は右向きに走り、先頭は右側。隠れるのは後方の一部。塔は上位3頭＋自分の竜の4行（約120px）に絞り、全頭は押した時だけ。以前ユーザーは「絵→声→順位の順」を指示した（8月）が、それは縦積みの時の並び。重ねると視線の往復そのものが消える＝指示の目的（読みやすさ）はより満たせる | 採用 |
| 自分の竜を大きく「5/8」 | 塔にも自分の行がある＝重複。だが塔は「全体の中の位置」、主役表示は「自分の賭けがどうなっているか」で役目が違う。賭けた人が一番知りたいのは「当たりそうか」＝「的中まであと何頭」を数字の横に添えて意味を持たせる | 採用 |
| 実況の箱をやめて字幕に | 実況は4行まで読める高さを保つ、という過去の判断（文章の質を削らない）。字幕でも1人あたり最大4行の高さを確保する。箱が無いぶん絵が透ける→下のグラデを十分に濃く | 採用 |
| 絵を伸ばす（上限480px→画面いっぱい） | 背景の絵（空・山・コース）が縦に足りるか。縦に伸ばして空が間延びしないか撮って確認。重くなる心配（塗る画素が増える）→端末の解像度は2倍までの既存の上限が効く | 採用（撮って確認） |
| 熱狂の演出（区間の切り込み・全幅の帯・ゴール） | 今回は骨組み。重なる位置だけ直す（上の帯・塔・字幕とぶつからない高さへ） | 位置だけ |

## 2. 予想画面 v2 ＝「冷静な一覧」＋「育つ賭け札」

### 今の骨組み
上の帯（約190px・貼りつく）／賭式タブ／出走カード（1枚76px・文字6種がほぼ同じ大きさ）／下のスリップ（**約300px・常に全部開いている**＝360×640 では画面の45%）／相談役。

### v2 の骨組み
```
┌──────────────────────────────┐
│ ← 新人競竜杯 第4R   🪙1,000  │ 1行のヘッダ（作品名は出さない）
│ グランドクロック・短距離・晴れ │
│ ▁▁▁▁▁▂▂▂▂▂▃▃▃▃▃              │ コースの図：序盤・中盤・終盤の3区間を横に。

├──────────────────────────────┤

```

### 決めごと
- 文字の大きさは4段だけ：見出し 20 ／ 名前 15 ／ 本文 12 ／ 補足 10.5。数字（オッズ・払戻）は 20〜28 の別枠
- 金は「選んだ竜」と「押すボタン」だけ。賭式の切替は中立
- 竜の絵はカードの主役として大きく（今の1.4倍）。識別の丸札は左上

### 自己批判
| 案 | 批判 | 判定 |
|---|---|---|
| 賭け札を畳む（要約1行→押すと広がる） | 賭け金を変えずに出走したい人が多い（初期値100）ので要約から直接「出走」を押せるようにする。畳んだ状態でも払戻が見える＝判断材料は欠けない | 採用 |
| ヘッダから作品名を外す | 共通ヘッダは全画面共通。予想画面だけ別の帯にすると食い違う → 予想画面では共通ヘッダを隠し、その役目（コイン）を予想画面の帯に持たせる。レース画面が既に同じやり方（走行中はヘッダを隠す）＝前例あり | 採用 |
| コースの図 | 「何が問われるか」は既にレース中の切り込みで出している公開情報＝予想の時点で見せても勝ちやすさは変わらない（能力の目盛りを行に出す案は、難しさが変わるので前回同様しない） | 採用 |
| 出走カードの絵を大きく | 1画面に見える頭数が減る（今6頭→5頭程度）。だが文字の行を3行→2行に減らして高さを保つ | 採用（頭数を撮って確認） |


## 3. 作ったあとの評価（2026-11-26・音を消した裏のブラウザで 390×844／360×640／PC枠470 を撮影）

### レース画面
良くなった：
- 走る絵が 390×844 で 784px（画面の93%）、360×640 で 579px。以前は約半分
- 左の順位の塔（上位3頭＋自分の竜・的中ラインつき）と、左下の「ちび紫竜 4/8　的中まで あと3頭」で、賭けた人が知りたいことが絵から目を離さずに読める
- 実況は箱なしの字幕。1人4行の高さは残した

作って分かった失敗と直し：
- 発走前に「—/8」と意味のない数字が出た → 発走前は賭けの内容（ワイド 100コイン → 的中なら 750）だけ
- 自分の竜の表示が地面の竜と重なって読みにくい → 文字の後ろに薄い暗がり
- 「LIVE」が右の字幕に重なった → 一時停止の下へ。ゴールの帯が上の帯とぶつかった → 下げた
- ゴール後、絵の中の「ハズレ −100 コイン」の札が字幕に隠れた → ゴール後は字幕を引っ込める
- 「結果を見る」が押せないように見えた（操作ボタンを中立の面にした指定が金の指定より強く効いていた）→ 金に
- 360幅で操作の列が2段に折れた → 1段に

### 予想画面
良くなった：
- 上の帯が「戻る・レース名・所持コイン」の1行＋条件＋コースの図（序盤・中盤・終盤の地形と効く能力）
- 出走カードは絵が主役（112px）、名前15px、いまの賭式のオッズだけを大きな札（22px）。選ぶと札が金に
- 賭け札は畳んだ状態で約160px（以前は約300px）。選んだ竜・賭け金→的中時の払戻・出走ボタンが揃っていて、そのまま出走できる。賭け金を変える時だけ広げる

作って分かった失敗と直し：
- もう一方のオッズの小さな行が「▾ 見る」と重なった → いまの賭式の札だけ
- 丸札の横の「人気」が竜の絵の上に乗った → 外した
- 地形名が「スター／ト」と1文字だけ折れた・360幅で切れた → 1行に収まる大きさ＋狭い画面では記号を外す
