# 暮らし×物語 結線再設計（正本）— KURASHI_STORY_WEAVE

目的：暮らしの中身（くらしツリー/生活資産/島の経済/観光/習い事/コレクション）を
**物語とフラグに双方向で絡める**。解放ゲート（済）に加えて——
- **A. 中身の章連動**：いま何話かで各画面の「声」と「お題」が変わる
- **B. 暮らし→物語の還流**：暮らしの行動が日報記事・小イベント・手紙を生む

鉄則：全部 **表示専用メタ**。レース着順/オッズ/配当/FinalPower に一切触れない
（[[race-math-immutable]]）。既存の拡張チャネル（STORY_EVENTS 1行追加・SNS投稿/
手紙追加前提・progression 台帳追加）だけで組む＝新システムを発明しない。

現在章の取得：`kurashiChapter()` = 既読済み最大章（`_chapter_intro_N` の最大N、
ED後=6）。js/progression.js に共通ヘルパとして追加し全画面から読む。

---

## A. 中身の章連動（画面ごと）

### A1. 🏦 島の経済 → 聖龍日報「経済面」
- ヘッダを新聞面化（.news-* 既存クラス・物語画面と同じ紙面言語）。
- **章別リード記事**（データ駆動 `KURASHI_ECON_ARTICLES[chapter]`・各1本）：
  - 2話=ミズ「市況解説：オッズと群衆心理」／3話=スミカ「総資産という物差し」／
    4話=マクラ「配信経済圏、島を回す」／5話=セレスティア期「避難基金と絶滅メーター」／
    クリア後=「復興景気、続く」。談話1つ＋数字1つを本文に差し込む（followers等）。
- 景気ティア到達で **台帳 toast**（B1）と記事が同期。

### A2. 🌳 くらしツリー → 「スミカの宿題」
- 画面上部に章別お題ストリップ（`KURASHI_TREE_HOMEWORK[chapter]`＝推奨3ノードの
  チェックリスト・達成表示のみ・報酬なし）。3話=食と住の基礎／4話=装と遊で配信映え／
  5話=全枝バランス。
- 各枝ヘッダにスミカ談話1行（章で差し替え・`branchVoice(branch, chapter)`）。

### A3. 🏝️ 観光マップ → 「いまの話の舞台」章スタンプ
- スポットカードに `stampChapters:[N]` メタを追加（data側1行/スポット・任意）。
  現章に該当するスポットへ 📰「いまの話の舞台」バッジ＋日報風キャプション1行。
  例：2話=場外・市場／3話=住宅地・古布屋／4話=縁日・中継スポット／5話=星見台・奥地。

### A4. 🎫 習い事 → 「師範」制
- スキル系統に師範を紐付け（表示のみ）：酒場系=サケ／分析系=ミズ／暮らし系=スミカ／
  配信系=マクラ。カードに師範アイコン＋一言。師範の登場章前は名を「？？？」表示
  （progression のロック2表現に合わせる）。

### A5. 🎁 生活資産・🏆 コレクション
- 生活資産：lifeStage アップ時に日報「暮らし面」引っ越し記事（B2）。
- コレクション：クリア前は暮らしハブに「？？？（終章のあとで）」の予告行を出す
  （既存ロック表現の流用・中身は変えない）。

## B. 暮らし→物語の還流（新規：暮らし還流台帳）

`js/progression.js` に **KURASHI_WATCH 台帳**を追加（解放台帳と同型・toast通知）。
各エントリ＝ {id, 条件(state)=>bool, 反応チャネル}。反応は既存3チャネルのみ：
1) **日報記事**＝STORY_EVENTS へ小イベント1行追加（js/data_story_events.js）
2) **SNS**＝タイムライン投稿 or ファンレター追加（js/sns.js のデータ配列）
3) **toast**＝progression の既存通知

| id | 条件（表示メタのみ） | 反応 |
|---|---|---|
| econ_tier2..5 | 景気ティア到達 | toast＋経済面記事（A1と同期） |
| tree_5 / tree_15 / tree_30 | lifeNodes ≥ 5/15/30 | 文化面小イベント（スミカ） |
| move_up | lifeStage ≥ 2/3/4 | 暮らし面引っ越し記事＋ファンレター |
| meals_10 / meals_25 | 食べ歩き品数 | グルメ面小イベント（みみしんぼ外伝） |
| spots_8 / spots_20 | 観光写真閲覧数 spotsSeen | 文化面小イベント＋手紙「写真見たよ」 |
| skill_master | 習い事いずれかLv最大 | 師範からの手紙 |
- `spotsSeen` は state.player.kurashi.spotsSeen（新設・閲覧spot idのSet相当配列）。
  その他は既存カウンタを読むだけ。**新カウンタはこの1個だけ**。

## 実装ウェーブ

- **K1 設計書**＝本書（済）
- **K2 還流エンジン**：kurashiChapter()＋KURASHI_WATCH＋spotsSeen 記録＋
  小イベント/手紙/投稿データ約12本執筆（キャラ声厳守・新聞調）
- **K3 画面の章連動**：A1経済面→A2宿題→A3章スタンプ→A4師範（この順・各々独立デプロイ可）
- **K4 通し検証**：新規セーブで2話→5話を devcheck 手順で流し、章切替で各画面の声が
  変わること・還流toastが出ることを確認→デプロイ

検証メモ：章は `_chapter_intro_N` を eval で立てれば再現可。すべて表示専用なので
既存セーブ互換（新フィールドは init ガードで後付け）。
