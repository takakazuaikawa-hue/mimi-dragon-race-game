# CODEX_MANJU_BRIEF — ゆっくり実況の饅頭立ち絵 7点

レース画面の実況ゾーン（左＝実況／右＝解説）に置く、いわゆる**ゆっくり霊夢・ゆっくり魔理沙風の「饅頭」**アイコン。
納品先 `images/race_live/manju_<key>.webp`。配線は実装済みで、**置けばそのまま出ます**（未納品時は
`onerror` で画像だけ隠れ、名前タグと吹き出しは成立する作りになっています）。

---

## 共通仕様（全7点）

| 項目 | 値 |
|---|---|
| 形式 | WebP・**透過必須**（背景は完全透明） |
| サイズ | **512×512 の正方形**（表示は40×40。将来の拡大に備えて大きめで納品） |
| 構図 | 饅頭を中央に。上下左右に**余白8%程度**。見切れ厳禁 |
| 向き | 正面。わずかに傾ける程度は可 |
| 表情 | **1体につき1表情（通常顔）**。表情差分は今回は不要 |

### 「饅頭」の定義（最重要）
- **顔だけの、丸くてぷにっとした団子状のデフォルメ**。首から下は描かない。
- 輪郭は**真円に近い楕円**。頬の下がわずかに広がる「まんじゅう」型。
- 目・口・眉は**極端に単純化**。塗りは3〜4色まで。影は1段だけ。
- 髪と髪飾りだけで誰か分かること。**これが唯一の識別子**です。
- リアル頭身・半身像・全身像は**すべて不可**。既存の立ち絵の顔だけ切り抜くのも不可
  （情報量が多すぎて40pxで潰れます）。

### 描かないもの
体・手・脚・武器・小物・背景・地面・落ち影・枠線・テキスト・ロゴ。

## 検収基準

1. **40×40 に縮小しても、7人が互いに見分けられること。** これが唯一かつ最大の基準です。
   縮小して隣に並べ、髪型と色だけで判別できるか必ず確認してください。
2. 背景が完全に透明で、暗い背景（`rgba(8,11,17,.62)`）に置いても縁が出ないこと。
3. 正方形で、饅頭が中央にあり、どの方向にも見切れていないこと。
4. 7点で**塗りの厚み・線の太さ・デフォルメ度が揃っている**こと。1点だけ書き込みが多いと浮きます。
