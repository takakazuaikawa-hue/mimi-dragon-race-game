# RACE_START_FAIR_ALIVE — 公平に見えるスタート＋竜の「生きてる・愛される」画像処理（実装:Opus4.8）

> 課題（ユーザー診断）：①斜め整列はレースとして**スタートが不公平に見える** ②竜のライブ感・
> 愛され感が足りない。SCOUT_REBORN_BRIEF の絶対規律1〜7を全条適用。
> ⚠️着順/オッズ/配当/timelineは不可侵＝以下すべて表示層。実装先＝js/race_canvas.js（canvas内）。

## A. スタートの正解案（検討済み・この案で実装する）
検討した3案：(a)真縦一列＝幾何学的に公平だが8頭が重なり読めない
(b)斜めゲートバー＝斜め列を「奥行きのある実線ゲート」として正当化
(c)ロールコール＝1頭ずつ前面紹介。**結論＝(b)+(c)の合成**：
幾何の公平さは「全員の鼻先が同じテープに触れている」ことで示し、
個体の見せ場はロールコールが担う（(a)の重なり問題も同時に解消される）。

### A-1 斜めスタートテープ（不自然にならない描き方）
- 現行の待機整列（x=34%cw−ln*7px・y=各飛行高度＝斜めの縦列）は維持し、
  **全頭の鼻先を結ぶ斜めの「発走テープ」を canvas に描く**：上端（奥）と下端（手前）に木柱、
  柱間に金色の光テープ2本（微妙に揺れる sin）＋小旗。奥の柱は細く・淡く（空気遠近）＝
  「斜めなのは遠近だから」と目が納得する。テープのx＝各竜の鼻先xと厳密一致（ln*7の同じ式で引く）。
- **GOの瞬間＝テープが弾け光の粒に**（spawnSpark数発＋テープ消滅）。ゲート解放の快感。
- 描画位置＝竜より奥（竜の描画ループの前）。既存の START 塔はそのまま。

### A-2 ロールコール（入場中の1頭ずつ紹介＝愛され感の入口）
- 入場パレード（S.entryT・ENTRY_DUR≈9s）中、**到着した竜から順に約0.8秒ずつフォーカス**：
  対象だけ scale×1.22＋白フチ発光＋頭上に名札プレート「⑦ 旋爪竜ロッソ｜差し｜単2.9」
  （canvas描画・枠色バー付き）。同時に実況テロップへ「7番 ロッソ、入場！」を1行差し込む
  （_hypeLines と同じ流儀・pumpEntranceTelop の仕組みに乗せる）。
- 自分の賭け竜の番だけ：金フチ＋♪SE（Sfx.tick）＋視聴者コメント（mineUpプール流用可）。
- 8頭終えたらカウントダウンへ（既存フロー不変）。スキップ操作中は出さない。

## B. 竜の「生きてる・愛される」画像処理（すべてcanvas・スプライトは不変）
1. **呼吸**：待機/低速時、y方向スケールを±1.5%・周期2.2s（竜ごとに位相ずらし）。
   走行中は既存の gait bob があるので**待機中のみ**。
2. **リムライト（HD-2Dの命）**：スプライトの輪郭に夕景の暖色（#ffb36a）1〜2pxの縁光。
   実装＝オフスクリーンで「シルエット化（source-in で単色）→1px拡大」を作り本体の下に合成。
   ★毎フレーム生成禁止＝(dragonId×スケール段階)でキャッシュ。まず待機/ロールコール時のみ適用し
   60fpsを実測してからレース中へ広げる（間に合わなければ待機中のみで確定＝それでも効果は大きい）。
3. **スピード残像**：intensity>0.85 の竜だけ、本体の後方6px/12pxに同スプライトを
   alpha 0.10/0.05 で2枚重ねる（キャッシュ不要・drawImage2回）。ゴール前の疾走感が跳ね上がる。
4. **首かしげ**：待機中、たまに（popCdと同じ間引き）±2.5°をease-in-outで1往復＝「こちらに気づいた」感。
   rotate は体中心アンカー（bodyCx）で。
5. **エモートの拡充**（data不要・既存 S.pops 流用）：ロールコール時に自分の竜が✨、
   ゴール後1着の竜に💕連発（既存ハートの流儀）、2-3着に👏。頻度は現行の popCd 間引きに従う。
6. **reduced-motion**：1/3/4は無効化、2は静的縁光のみ、5は頻度半減。

## 完了条件
- 入場→ロールコール8頭→テープ整列→GO弾け→レース→ゴールを通しで観戦（375＋PC枠）。
  スクショ＝①テープ整列（鼻先が全頭テープに接している）②ロールコールの名札フォーカス
  ③残像つき疾走 ④リムライトの待機絵。err0・資産照合・両ブランチ。
- パフォーマンス：リムライトはキャッシュ必須。実機相当で描画が落ちる場合は適用範囲を待機中に限定し、
  その判断を実施ログに記録。
- ⚠️プレビュー検証の罠：タブ非表示でrAF≈2fps・seek()は一時停止＆entryT=0になるため
  **ロールコールはseekでは再現できない**。タブを前面にして最初の≈12秒を実時間で確認するか、
  ENTRY_WALK/STAGGERを一時的に短縮するデバッグで確認し、戻してからコミットすること。
- 実装後、本書末尾に実施ログを追記。

# 実施ログ（2026-07-18）

## A 公平に見えるスタート ✅（案は実装中に修正）
- **A-1 テープ**：当初ブリーフの「斜めテープ」で実装したが、実プレイで2つの問題を実測——
  ①スプライトは鼻先アンカーで体が左へ伸びるため、斜め列の奥側ほど体が左端で見切れる
  ②斜めテープが竜の体に隠れて見えない（テープは竜より奥に描くため）。
  → **全頭の鼻先を同一x(42%)に揃える「真の縦一列」＋垂直の発走テープ**に変更。
  高さ(laneY)が竜ごとに違うので縦に積まれ、体は重ならず全員読める。
  公平さが幾何学的に自明（同じ線に全頭が触れている）＝当初案より目的に忠実。
  支柱は地面まで／テープ2本＋小旗6つ／微かな揺れ。**GOで6点の光の粒に弾けて消える**（tapeAlpha）。
- **A-2 ロールコール** ✅：入場終盤に1頭0.8秒ずつフォーカス（scale×1.22）＋頭上の大名札
  （人気番号／竜名／脚質・単オッズ＋枠色バー）＋実況へ「5番人気 セラム、入場！」を差し込み。
  自分の賭け竜だけ金フチ＋SE＋✨＋視聴者コメント。
  - **発見と修正**：入場終了時に S.roll を戻しておらず、最後に紹介した竜の名札が
    **レース中ずっと残っていた**（実測）。入場ブロックの末尾で S.roll=-1 に。
- seek同期：tapeAlpha/tapeBurst/roll もスクラブ位置に合わせる（GO後は消灯・巻き戻すと復帰）。

## B 生きてる・愛され感 ✅（4/5実装・1件は見送り）
- B-1 呼吸：待機中のみ縦±1.5%・周期2.2s・竜ごと位相ずらし（走行中は既存gait bobがあるので入れない）。
- B-3 スピード残像：intensity>0.85 の竜に後方6px/12pxをalpha .10/.05で2枚（drawImage2回＝低コスト）。
- B-4 首かしげ：待機中、竜ごとの周期で±2.5°を1往復（体中心アンカーで回転）。
- B-5 エモート拡充：ゴール後に1着へ💕×3・2/3着へ👏。ロールコールの自分の竜に✨。
- **B-2 リムライト（縁光）＝見送り**。オフスクリーンのシルエット生成＋キャッシュが必要で、
  今回の変更量（A全面作り直しを含む）と同時に入れると性能問題の切り分けが困難になるため。
  効果は大きいので次段の単独タスクとして残す。ブリーフの「間に合わなければ待機中のみ」より
  さらに保守的な判断＝**未実装であることを明示して次に送る**。
- reduced-motion：B-1/3/4を一括OFF（_reduceMotion）。

## 検証メモ
- プレビューは hidden タブで rAF が絞られ、**入場9秒が実時間で進まない**。
  ENTRY_WALK/STAGGER/SETTLE を一時的に 0.4/0.4/0.1 へ短縮して検証し、
  **本番値(3.8/5.0/0.6)へ戻したことを grep で確認**してからコミットした。
- 「GO前の整列＋テープ」フレームは `racePlayer.seek(0)` で作れる（tau=0 → tapeAlpha=1・entryT=0）。
  ロールコールだけは seek で再現不可（entryT=0にするため）＝入場短縮デバッグでのみ確認できる。
