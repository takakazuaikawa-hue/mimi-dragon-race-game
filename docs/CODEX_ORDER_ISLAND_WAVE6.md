- **実写と見まがうシネマティックな風景写真**。既存の `images/konron/spots/*.webp` と並べて同じ写真家に見えること。

  `hoshimi.webp`（夜）／`hoshiuo.webp`（漁村）／`market_gourmet.webp`（料理）。
- **明るい熱帯の火山リゾート島**：暖色・椰子・濃い緑・黄金色の光。寒色の霧、雪、針葉樹の森、灰色の空は不採用
  （第5波で `mori_no_sato`＝杉の冷たい森を、これで落としている）。
- **人物は匿名**：後ろ姿か逆光のシルエットだけ。顔を見せない。ときどき獣耳・しっぽ・角のある亜人を混ぜてよい。
  立ち絵のキャラ（ミミ・サケ・ミズ・スミカ・マクラ・セレスティア・ポロ）は**描かない**。
- **読める文字を入れない**（看板・のれんは模様か、判読できない装飾まで）。ロゴ・透かし・枠も不可。

### 地理（島の地図 `images/konron/island_map.webp` を必ず見る）
- **アレドラウ山＝島の中央に立つ、尖った活火山の峰**。噴煙は峰の先から細く立つ。
  **山頂に火口湖は無い／広い火口を覗きこむ構図は不可**（第5波で `kazan_observatory` をこれで落としている）。
- 西＝霧のミストラ湾と港町／南＝白砂の浜と黒い溶岩の海岸／東＝キビシスの海崖／北＝道のない荒い岩の海岸。
- **奥地（ダダケ村・スス深回廊・ロンド元宮・グワルガ・饗会）は描かない**。写るとしても霧の向こうの遠景まで。
- 山は「ひとつの峰」。背景に別の高山や雪山、山脈を並べない（緑の丘・海崖・岩礁はよい）。

### 風土（`js/konron_content.js` の KONRON_GUIDE「気候・風土」が正本）
- 風は一年じゅう**東から**。東の崖で吹きあがる（吹き流し・草・髪は、崖の上では下から上へなびく）。
- 山のかげになる**西は凪いで霧**、**南は晴れて乾く**。雨と霧が多いのは山の東と北。
- 家のつくり：壁は溶岩石（黒〜濃灰）と赤土、屋根は茅か素焼きの瓦、**軒が深い**。入江の家は高床。
- 火山の恵み：黒い火山土、溶岩石の石畳とかまど、地熱の湯気。

### 寸法と形式
- スポット写真：**1264×848px・webp・品質82前後・220KB以下**（既存と同寸）。
- 料理写真（`_gourmet`）：同寸。**真上〜斜め45度の卓上**、手や袖が少し写るのはよいが顔は入れない。
- 歩ける地図（§B）：**1920×1440px・webp・600KB以下**。
