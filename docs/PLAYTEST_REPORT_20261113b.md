## 3. 財布の出来事はミミの反応になったか（遊んだ感想）

### 初めての服は、成功した

Aの1,600→100は、こちらが暗算して意味を足さなくても分かる。「買うと100」を見てなお押し、ミミが慌てるので、失敗の責任も喜びも自分と本人にある。直後の強がりと、ホームの「えへへ、新しい服……！」の矛盾が可愛い。[購入後のホーム](playtest_shots_20261113b/11_A_home_purchase.jpg)。

この初回はしつこいとは感じなかった。長い説明を足したのでなく、喜びに値札の痛みを刺したからだ。Bの残り50も同じ。今回いちばん効いた修正。

### 1,000の補充は、少なくともランク1では白けにくい

Aは無心のあと900→1,190→1,090。小さな賭けでは、ただ苦しめられる感じにならなかった。服を買う前の豊かさに戻ったわけでもなく、食事のおごりも人情として入る。今朝の「破産すると服三着ぶんが来る」という印象は、この区間では消えた。

Bは補充直後の一戦でモムが当たり3,800になった。これは無心が財布を解決したのではなく、自分の賭けが跳ねた出来事として受け取れた。**補充1,000→自分で増やした、の順番は良い。** 大当たりの額や確率を変える提案ではない。

ランク2では5,542を受け取った。ここではまた大きな安全網を感じる。ただ、今回はミミも「服三着」と驚くので、大きさが黙殺されなくなった。長期にも貧乏が続くかは8戦では判断しない。

### 無心は、初回の人情より3回目の慣れが笑えた

最初の「顔を上げな」は優しい。爆笑というより、助けてもらった場面になる。3回目の袋の用意は笑えた。直前にこちらがまた服へ奮発しているので、村に行動を見透かされた感じがする。「回数が記録されてるんでしょうか」と本人が気にするホームの返しもつながった。

**「ド貧困のミミが失敗と笑いを繰り返して上がる」感じは、今回は出始めた。** 財布を失っても買った服は残り、姿は一段上がる。無心の通知だけを回している感じから離れた。ただし3回目への早い到達は、私の追加購入込みだ。

邪魔なのは、この掛け合いより、破産のたびに戻るサケの同じ導入と、ぱほの溜め・確認・受領の一式。村の人が「もう分かってる」笑いを出す横で、導線の方は毎回初回の説明をしている。

### ホームへのつながりには取りこぼしがある

服・無心・からっぽ・連敗の反応は、普通の挨拶よりずっとよい。一方、B4の大当たり後はくらしの授与や解放通知が先に来た。食事へ進み、戻って通知が消えるところまで待つと、「推し竜、見つかった？」「いっしょに当てようね！」になった。**まさに今モムに借りを返した本人へ、その質問をされると、関係が一歩戻る。**

反応を増やす方向は正しい。しかし、予約しただけで見た扱いになるなら、通知が多い節目ほど主役の一言が落ちる。§5に再現経路と読み取り確認を残した。

### 空腹は、導線が直っても作業だった

Aの塩むすびは「給料日前」の名前と、自分で握ったという文が楽しい。食後のレースへのボタンも分かる。ここまでは生活の寄り道になる。

Bは最安のバナナを選び、B4後〜B7後に4回続けて食べた。2回目からは、同じカード、同じ感想、同じ食べるボタン、同じ帰るボタンを通す。**毎回の迷子は減ったが、毎回の家事は残った。** 次のモムを見たい気分の前に、バナナの確認係になる。値段や減り方の調整は求めない。既に知った一皿へ短く戻れる導線と、繰り返し時の表示量の問題だ。

### 結果画面は読みやすくなった。必要な情報も失っていない

外れと財布の増加を分けて読め、最後の残高・空腹で次の行き先を判断できる。重複していた払い戻し3行と締めの一言が無くなって、同じことを読み直す感じが減った。B4で「払い戻し」タブを実際に開き、賭金200・払戻3,000・収支＋2,800を確認できた。必須の内訳が消えたとは感じない。

今朝の残存事項は§1へ集約した。ここは今回の場面から、新しく重かった点。

### 1. 食事：二度目からの生活が、同じ手続きをするだけになる

B5〜B8の出走前。初めてバナナを見つけるのはよい。その次も12枚の一覧から同じ皿を探し、既に読んだ講評を通り、食べ、帰る。「何を食べよう」から「先へ進むために、あのボタンを押す」へ変わった。空腹の入口を正しくしたぶん、この反復が前面に出た。

**どう直すか：** 食事一覧の上に、前回食べた一皿を価格・回復量つきで一枚だけ置く。既食の皿は食べた結果とレースへのボタンを中心にし、長い感想は任意で読めるようにする。価格・回復量・消費量・食べる回数には手を入れない。

### 2. ホーム：主役の反応より、解放通知の処理が先に残る

B4でモムへのリベンジが当たる。ところがホームの到着は「缶コーヒーを飲み残せる」、食事へ進むと「床じゃなく布団」、戻ると図鑑解放の帯。生活が上がった知らせ自体はよいが、その間に大当たりへの本人の反応が消えた。今回の修正のいちばん大事な部分が、一番おいしい場面で後回しになる。

**どう直すか：** 財布の一言を、実際に出した時点で既読にする。画面を離れたら次のホームまで持ち越す。大当たり・購入・破産の直後は、その一言を授与通知より先に短く出す。新しい通知や説明窓は増やさない。

### 3. 結果：最大のご褒美の見出しが、意味の途中で折れる

B4・375px。「伝説の的中！！！」が「伝説の的／中！！！」になる。[全体](playtest_shots_20261113b/01_B4_hit.jpg)。主役の言葉が大きいのは正しいが、ここで一番整っていてほしい日本語が崩れる。黄金の枠や額が立派なぶん、組版の未調整が目立つ。

また、財布と横いっぱいの次ボタンは良くなったのに、結果を開いた最初の画面では見えない。全8頭・勝負所・島時間を送った先にある。情報を減らした成果を、日々の反復の速さへまだ渡せていない。

**どう直すか：** 長い的中見出しは「伝説の／的中！！！」など意味の塊で折る。次の操作と財布の小さな行は、結果画面の下端に残す。着順表や払い戻しの情報は保ったまま、読むことと先へ進むことを両立させる。

### 4. 物語：読み終えたあと、また記事の冒頭に戻るだけで熱が切れる

A6後・第2話。会話→大きな文字→記事の一本道は成功した。しかし、最後の「読み終える」を押すと同じ本文の冒頭へ戻り、出口は物語一覧。ミズに会って面白くなった気持ちを、次の遊びへ渡す手がない。話を読む操作は分かっても、読んだことの手応えは紙面の中で終わる。

**どう直すか：** 演出読了後の紙面に小さく「読み終えた」を示し、その話で開いた機能へ一つだけ進める。第2話なら、次の出走表で分析予想を見てみる入口。未解放の先の話を見せたり、別の説明会話を足したりする必要はない。今回、分析予想そのものは操作していないので、その品質の評価ではない。

### 5. 紀行の入口：自分で積んだ記録と、既にある案内が見分けにくい

A6後。遠出も写真撮影もしていないのに、「集めた記録を、読みかえす」の下に島さんぽ24/33、フォト日記49/94が並ぶ。これが訪問・撮影の実績なのか、解放された案内の数なのか、入口では分からない。今回新しく食べた1/44は自分の記録だと分かるので、隣の大きな数との意味の違いが気になる。[入口](playtest_shots_20261113b/20_A_kiko.jpg)。

「明日は自分で一枚増やしたい」につなぐ場所で、既に半分以上埋まっているように見える。数が誤っていると断定する不具合ではなく、表示の意味と所有感の批評。カテゴリの中身は今回開いていない。

**どう直すか：** 既存の数が何を数えているかを、見出しで明示する。「公開中の島案内」「掲載写真」等、実際の定義に合わせる。日々の記事には、直近の自分の出来事だと分かる短い日付・戦数を添える。新しい収集数や報酬は足さない。

## 5. 不具合（再現手順つき）

**14戦で、再読み込みが必要な完全な進行停止は確認していない。** 以下は会話の表示・操作、主役の反応、財布の表示の問題。着順・オッズ・配当の計算の不具合とはしていない。

### 優先1：初回食事の会話が料理窓の裏に出て、移動後まで残る

1. 新規セーブから食事をせず4戦し、空腹0にする。
2. ホームの「ごはんを食べて、レースへ」から自宅ごはんへ。
3. 初めての一皿を開き、「いただきます」を押す。
4. 食後の料理窓と「このまま、レースへ」が出る。一方、初回食事のミミの会話も、その窓の裏で始まる。
5. 料理窓が会話欄を覆うため、通常の会話送りが押せない。
6. 料理窓の「このまま、レースへ」は押せる。押すとレース選択へ移るが、そこで食事の会話が現れ、送る必要がある。

A4後の塩むすびで確認。B4後の初回バナナでも、料理窓と初回会話の同時表示を記録した。[料理窓](playtest_shots_20261113b/17_A_food_exit.jpg)。Aの `A_food_visible_continue`／`A_food_arrival` には、レース選択と「塩むすび……おいしい」の会話が同時に残っている。

**期待：** 食後の会話と料理窓を順番に出す。食事の一言を読んでから、窓の主ボタンで次へ進める。回避できるので完全停止ではないが、今回の主役である食後の反応が正しい場面で読めない。

### 優先2：通知待ち中にホームを離れると、財布の一言が未表示のまま消費される

1. B4のように、初的中・ランク昇格・解放通知が重なる場面で、5倍以上の単勝を当てる。
2. 結果からホームへ戻る。今回のB4はモム15倍、配当3,000、財布3,800。
3. くらし授与などの通知が出ている約2.5秒後、表示された食事ボタンを押す。
4. 食事画面からホームへ戻り、通知が消えるまで待つ。
5. 大当たりへの反応が出ず、通常の小話になる。

B4の初回到着と、食事から戻った到着で確認。戻った画面では通知後に「推し竜、見つかった？」「いっしょに当てようね！」を記録した。ログは `B4_home_bigwin` と `B4_home_bigwin_wait6〜16`。待ち秒数は重いPCの実測であり、固定の再現条件とはしない。

読み取り確認でも、`js/ui_home.js` の `homeWalletLine` は、発話前にイベントを消し、レースを既読扱いにする。実際の発話は後の `whenUiIdle` で、離脱すると表示を中止する。そのため「見ていないが、次の到着では既読」の経路になる。

**期待：** 実際に吹き出しを表示した時点で消費する。離脱時は持ち越す。今回は一つの実プレイ経路と静的な確認であり、全通知の組み合わせを網羅した試験ではない。

### 優先3：食後の窓が、現在残高から「もう一食分」を引く予告を無印で表示する

1. A4後、財布900で塩むすびをおごりで食べる。
2. 食後の主ボタンが「このまま、レースへ」になった窓を見る。
3. 無料の食事を終えたのに「70コイン」「所持900 → 残り830」と出る。
4. レース選択へ戻ると実際の財布は900のまま。

有料でも同じ。B4後は3,800から50を払って3,750になった直後、窓に「3,750 → 3,700」。B6後も542→492を払った後で「492 → 442」。次の一皿の予告としては計算が合うが、食べ終えた窓の主役はレースへ進むボタンなので、**今食べた代金か、もう一度食べる代金かが分からない**。[無料食後の窓](playtest_shots_20261113b/17_A_food_exit.jpg)。

二重にコインが引かれたとは確認していない。表示の誤解。支払い済みの結果を表示するか、「もう一品食べると」を二度目の食事ボタンの横へ明示する。
