# 指示書：ホーム画面デザインモック（Codex向け）— 商業レベルの「配信ホーム」

聖龍爆走録ミミのホームを商業モバイルゲーム品質へ再設計する（正本=docs/HOME_COMMERCIAL_REDESIGN.md）。
その**見た目の方向性を決めるデザインモック**を先に作る。⛔ゲームコード変更・デプロイ禁止。

## 出力
`images/mock/home_v2_A.png` と `home_v2_B.png` の2案（縦 470×1000前後・1枚絵のUIモック）。
モックは「絵」でよい（実装はこちら）。文字は日本語で実物どおりに入れる。

## 共通レイアウト（この構造は両案で固定＝情報設計は決定済み）
1. **ヘッダー**：左=プロフィールピル（🐰アイコン・予想家ミミ・ランク5・3連勝）／右=🪙910万・🔊・⋯
2. **ヒーロー（配信）**：バニーガールの大立ち絵（シルエット可）＋夜の火山島の窓背景。
   左上=🎯目標チップ（小）・右上=🔴LIVE・👁5,034・💗17.8万。
   下部=流れるコメント2〜3行＋「コメントする…」入力ピル＋❤️ボタン
3. **メインコマンド**：金色の大CTA「🐲 レースへ進む」（画面で唯一の金）
4. **フッター＝固定タブバー5枠**：🏝島・🌳暮らし・🐲レース（中央・一回り大きい）・📖図鑑・📱SNS
   ＋SNSタブに赤い未読ドット・「島」タブに🔒版のバリエーションも小さく添える（未解放表現）

## 2案の違い（ここだけ変える）
- **A案「ネオンライブ」**：TikTok Live×ネオン。深紺の地にピンク〜金のネオングロー、
  タブバーはガラス（すりガラス+発光縁）。コメントは黒半透明ピル。派手め・若い。
- **B案「聖龍の宿」**：和風ファンタジー寄り。深緑〜漆の地に金の縁飾り・提灯の暖光、
  タブバーは漆塗りの板に金アイコン。聖龍日報の紙質感をチップに少し。落ち着き・世界観重視。

## 品質基準（商業レベルの判定）
□ 3秒で「次に何をするか」（CTA）が分かる □ 金色がCTA以外に無い
□ タブ5枠のアイコンが小さくても判別できる □ 余白と角丸が全要素で一貫
□ 文字サイズ階層が3段以内 □ 立ち絵とUIが喧嘩しない（UIは立ち絵の顔を隠さない）
