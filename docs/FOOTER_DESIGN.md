# 下部ナビ（フッター）設計 — FOOTER_DESIGN

ホーム下部の5タブ＝ゲームで最も指が触れる面。提案書（3案）から**案A「静かなガラスドック」**を採用（ユーザー選択）。
関連：[[home-tiktok-live]]（配信ホーム）・NAV_ICON_SPEC.md（専用イラスト）・SCREEN_SIZE_RULES.md（枠）。

## 採用＝案A「静かなガラスドック」
すりガラス1枚・フラット・装飾を足さない。**専用イラストアイコンが主役**になる“余白の設計”。
世界観を邪魔せず、普遍的に読みやすく、実装が堅い。（不採用：B島の桟橋＝テーマ全振り／C浮遊セグメント＝密度で解消）

## 原則（リサーチ）— 数値はここが正
| 項目 | 値 | 理由 |
|---|---|---|
| タップ領域 | **≥48px**（実装 タブ55×63px） | 指先が迷わない最小（iOS44/Material48） |
| バー高さ | **規定**（実測73px＝内容52＋余白＋セーフエリア） | 「高さ未規定」の是正。下端ホームバー回避 |
| アイコン | **26px**（モバイル25px） | ラベル10pxは**常時表示**（迷わせない） |
| 押下 | **沈む**：scale .92＋淡い面 | 触った実感（フィードバック） |
| 構成 | 行き先**5枠**：島/暮らし/ごはん/SNS/龍舎 | レースは金CTA（フッターに置かない＝二重導線回避） |
| 可読性 | ヒーロー上でも沈まない | ガラス地＋blur＋内側1pxハイライト |

## 実装の要点（style.css `.hl-dock .tik-*`）
- バー：`rgba(14,16,30,.62)`＋`blur(15px)`＋角丸18px＋上向き影。
- タブ：`min-height:52px`（モバイル50）・`justify-content:center`・`border-radius:14px`。
- アイコン：絵文字26/25px、専用イラスト`.tik-ic-img`は30/28px（箱方式・NAV_ICON_SPEC.md）。
- 押下：`.tik-tab:active { transform: scale(.92); background: rgba(255,255,255,.08) }`。
- 等幅flex（旧gridの中央太りは廃止＝レースタブ撤去に伴う・SCREEN_SIZE_RULES.md）。

## 検証
- 375/390/430で タブ≥48px・横スクロール無し・5タブ均等（配信）/4タブ（静か）。
- 専用イラスト（island/kurashi/meal/sns/stable）を置くと更に充実＝スカスカ解消の本命。
