## 0. 絶対規律（全フェーズ共通・違反したら差し戻し）

1. **レース数値不可侵**：着順・オッズ・配当・FinalPower・timeline・resolveBet に一切触れない。
   新要素はすべて表示メタ（race_engine.js / odds_engine.js / betting_engine.js を開かない）。
2. **通貨を増やさない**：報酬は既存6種（コイン/総資産/暮らしP/ランク/モール内メダル系/衣装）に落とす。
   モールのゴールド/チケット/みがきは「モール専用・コイン非干渉」を維持。
3. **登場門番**：キャラは advisorMet()/castNameSafe 経由・fail-closed。新台詞に未登場キャラを直書きしない。
4. **負けても物語が戻らない（spec#30）**：恒久成長・レベル・図鑑・スタンプ・衣装既得権
   （outfitsWon）は**いかなる失敗でも失われない**。リスクは「未確定のボーナス」にだけ載せる（§4.2）。
5. **文章の規律**：説明は1行＋？ボタン。読ませたい場面だけ文字送りで演出。中身のない文は書かない。
6. **デプロイ**：CSS/JS変更→ index.html の `?v=` を **perl で一括更新**（PowerShell禁止・文字化け）
   → main へ push → flying-pixel-dragons へ merge & push。壊れたコードを push しない。
7. **検証してから完了と言う**：機能の核を先に定義し、データ（シミュレーション/監査ツール）＋実機の
   両方で実証してから完了報告。検査は「壊すと検出される」ことまで逆向きに確認する（§9）。
8. **スコープ規律**：各フェーズは本書に書かれた範囲だけ。良い既存部分に勝手な改善を足さない。

## 4. モールで大冒険 — 理想像と設計

### 4.1 理想像（1段落）
崑崙モールの観光客ラッシュを「満足させて帰す」コメディ・ローグライトRPG。1ラン10〜15分。
戦闘は読み合い（インテント×属性×状態異常）、ランはプッシュ・ユア・ラック（未精算ワゴン）、
目当ての服を狙って潜り、戦利品を抱えてレジを駆け抜ける。**狩って・買って・着る**が一筆書きに繋がり、
気絶しても人生は戻らないが「あの積み荷」だけは惜しい——その一点に緊張が宿る。

### 4.2 コア改修（M1〜M3）

**A. 戦闘の意思決定を取り戻す（M1）**
- スキル6種に**副次効果**を付与（新スキルは足さない・既存 RPG_STATUS 4種を再利用）：
  ぱきーん(氷)→2割でぐったり／ぱちぱち(電)→2割でチカチカ／ぱわー(力)→2割でぼうぎょダウン／
  ぱふぅ(回復)→自分の状態異常も1つ解除。物理と火は素の威力で勝負（差別化）。
- **ためる**コマンド新設：1ターン無防備（被ダメ×1.5）で次の一撃×2.2。敵インテントを読んで
  「今ためるか」を問う＝1ターン単位のリスク選択。
- **ボスと主(nushi)戦はオート戦闘不可**（クライマックスは手で遊ぶ）。雑魚オートは利便として残す。
- 数値は初期値。§9のシミュレーションで「ためる」の期待値がわずかに優位＋読み外し時に痛い、へ調整。

**B. 未精算ワゴン＝プッシュ・ユア・ラック（M2）**
- ラン中の獲得（ゴールド・チケット・衣装候補・みがき）は**ワゴン（未精算）**に載る。
- 各階の階段で選択：**「レジで精算」**（全額確定・そのフロアで打ち止めボーナス無し）or
  **「積んだまま上へ」**（未精算分の価値が1階ごとに×1.2。気絶すると**未精算分だけ**失う）。
- レベル・経験値・図鑑・自分磨き・精算済みは**絶対に失わない**（規律4）。失うのは欲張った上澄みだけ。
- HUDに常時「🛒未精算 ◯◯G（×1.4）」を表示＝リスクとリターンを1行で可視化（G2）。
- 初期値：倍率×1.2/階・気絶時損失100%（未精算のみ）。§9で「精算派と積み増し派の期待値が拮抗し、
  積み増し派の分散が大きい」に調整する。

**C. ショーウィンドウ＝狙い撃ち（M2）**
- ラン開始時に未所持衣装から**「本日の目玉」3着**を提示（ラン内固定・rarity混在）。
- 屋上ボス（タワーは5階ごと）撃破で3着から**1着を選んで**獲得。既存のランダムドロップは併存。
- ハブとフロアカードに「目玉まであと◯階」を常掲（ゴールグラデーション）。

**D. エレベーター3ドア択（M3）**
- フロア間の移動を「エレベーター画面」化：**3つの扉**から1つ選ぶ。
  🛍催事場（ワゴンセール＝時価の買物）／🚪開かずの店（強敵1体＋高額未精算）／☕ラウンジ（回復＋お香）／
  ❓ハプニング（コメディイベント・konron_content.js の店ネタ再利用）／⚔️団体様（連戦＋チケット）から抽選で3枚。
- 扉には**次の気配**（「甘い匂いがする…」等）を1行添える＝StSの「自分が何に耐えられるか」を問う。
- 既存の階段構造は温存し、階段到達→エレベーター画面→次フロア、の差し込み（作り直さない）。

### 4.3 負債の完済（M0・最初にやる）
1. docs/MALL_UX_BACKLOG.md の P0〜P2 全9項目を消化（各項目に受け入れ基準が書いてある）。
2. 「全48品」vs 実測46品：RPG_SHOPS を数え直し、ヘルプ文と rpgGrandCompCheck を**実数に合わせる**。
3. ハブ二重定義の解消：ui_mall_rpg.js を唯一のハブ実装にし、mall_rpg.js 側 rpgRenderHub は
   delegate（`return rpgRenderHub2(app)` 形式）に。後勝ち依存を根絶。
4. RPG_ENEMY_IMG と RPG_ART_ENEMIES の2系統を1系統に統合（HUD/canvas 双方が同じ台帳を引く）。

### 4.4 アートと音（M4〜M5・生成は §7）
- 敵20種＋ボスの**canvas戦場スプライト**を全数配線（512×512透過webp・既存納品9枚 en_*.webp と画風一致）。
- フロア背景 far/near（7階＋屋上）で一人称シーンの壁/床に質感を。
- BGM3曲：mall-day（買い物の高揚）/ mall-boss（店長戦）/ mall-fever（フィーバー）。SEは sfx.js 合成継続。

## 5. 島めぐり — 理想像と設計

### 5.1 理想像（1段落）
「読む観光」を**「撮る旅」**へ。スポットに着いたら構図を選び、シャッターの一瞬を狙う。見頃・天候・章で
同じ場所が違う顔を見せ、たまに横切る「シャッターチャンス」が幻の一枚になる。撮った傑作はSNSで伸び、
旅ノートに刻まれ、エリア制覇が称号になる。ガイドの職業病ボケと共に、崑崙島を**もう一度歩きたくなる**。

### 5.2 撮影ミニゲーム（T1・体験の核）
- スポット詳細に **「📷 撮影する」**（photo保持スポットのみ）。流れは2手＋結果：
  1. **構図3択**：スポット写真の3クロップ（寄り/引き/ナナメ＝CSS object-position で切る・新規画像不要）。
     正解クロップは日替わり（日付+spotId ハッシュで決定的）。**ヒントは `shoot` 文言とガイドの一言**
     （例：shoot「湯けむり越しの朝日」→正解は"引き"）。ヒント→正解の対応表をデータで持つ（§9で全数監査）。
  2. **シャッタータイミング**：フォーカスリングが収縮→中心で1回タップ。ジャスト±130ms／グッド±300ms
     （スカウトのダンス実装 scout_game.js のタイミング系を流用・実証済みの手触り）。
  3. **☆評価**：構図正解+1☆／ジャスト+1☆／基礎1☆ ＝ ☆1〜3。**見頃（time一致）なら グッド→ジャスト昇格**。
- **失敗状態なし**：☆1でも訪問・スタンプ・ミッションは成立（A Short Hike）。☆3＝**傑作**：
  ギャラリー金枠・SNS投稿の反応が跳ねる（表示専用）・旅ノートに登録。
- 既存の「今日の一枚」ミッションは「そのスポットで☆2以上」に置き換え＝当て要素が初めて遊びになる。

### 5.3 再訪の価値（T2）
- **シャッターチャンス**：撮影中、低確率（日付+spotId決定的・約12%）で「！」が横切る
  （翼竜/子竜/精霊光/謎のお姉さん(第4話後・門番経由)…エリア別テーブル）。タイミング成功で
  **幻の一枚**＝専用キャプション＋図鑑バッジ。何が出るかは教えない（余白3割）。
- **見頃の拡張**：time×天候(_kmIslandNow)×章で `shoot`/`line` の差し替え変種を各スポット2〜3本
  （テキストのみ・画像流用）。「いまが見頃」バッジは既存を活用。
- 章スタンプ（KM_STAMP）連動：現章の舞台スポットで撮ると日報風キャプションが付く（既存11＋拡充）。

### 5.4 旅ノートと報酬の閉じ（T3）
- **旅ノート**画面（ギャラリーの隣タブ）：エリアごとに「スタンプ◯/◯・傑作◯枚・実食◯品・制覇度」を
  1ページに。エリア制覇で**称号**＋ホーム🎯目標と連動。全エリアで「崑崙路の写真家」称号＋記念衣装1着
  （既存OUTFITS の assets 条件枠を流用＝通貨は増やさない）。
- **隠しスポット**：？？？ピンを2〜3件新設（例：食事 g_pasta を実食→「看板のない店の裏路地」が出現）。
  発見条件は食事/SNS/物語の**既読データから引く**（告知しない・気づいた人だけ）。
- **スカウト結線**（C4解消）：観光スポット⇄スカウトロケ対応表（崖⇄キビシス/火山⇄カルデラ…）を新設し、
  スポット詳細に「🐾 この辺りで竜の気配」チップ→renderScout へ（表示専用・ryusha 1点経由を面に）。

### 5.5 レース8地域の完成と充填（T0/T4）
- **T0**：孤児PNG約23枚（grandclock.png 等）を**1枚ずつ開いて検収**：アートバイブル
  （docs/konron/KONRON_IMAGE_PLAN.md §0 の方角/画風/主役ルール）に合格→webp化して `rg_*` に結線。
  不合格→§7で再生成。8地域全てに photo＋KONRON_CONTENT（ミミの旅メモ一人称）を付け、
  レース結果画面から「今日走った土地を見にいく」チップ（next_suggest）で島めぐりへ。
- **T4**：KONRON_CONTENT 未執筆26スポットを「ミミの旅メモ」一人称で充填（ガイドブック文体禁止）。
  到着VNのボケ変種を各ガイド+2本（ミズ=原価を言う/スミカ=整理券を配る/マクラ=構図に口を出す/
  サケ=説教が長い/セレスティア=スケールがおかしい/ポロ=泣く）。天丼はエリア制覇時に1回だけ。
- **小掃除**：`ui_konron_map.js:186` の到達不能文言を削除。値オブジェクトに id を持たせ脆さを解消。

## 6. 全体のまとまり — 感情曲線と結線（C1）

## 6.5 暮らしスキルの散りばめ — 遊ぶほど暮らしがそろう（K1/K2・ユーザー発注 2026-07-25）
