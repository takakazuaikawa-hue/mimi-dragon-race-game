## 2. 今の画面をこの物差しで見る（本番 20261123e の実画面）

予想画面（＝「冷静」の場面）：
1. **冷静の場面なのに派手**。画面全体に舞う火の粉の粒（`.s4-embers`）、上の帯の地域色グラデ＋金の下線、金の枠、選択の光彩、浮き出したタブ。TIPSTAR が捨てた「派手で賑やか」そのもの。←古く見える一番の理由
2. **色相が4つ競合**：地の青緑・カードの紫（#241c44）・金・茶。参照先はどれも「無彩の地＋役割色1〜2」
3. **竜の識別記号が画面ごとに違う**：出走表＝左の太い色帯、レース中の名札＝無色の札に順位の丸、順位表＝3pxの色棒。JRA は同じ「枠色の丸札」を全部で使う
4. 数字が小さく（オッズ14px）、全部の文字が太字で強弱が無い

レース画面（＝「熱狂」の場面）：
5. 走る絵の上に8頭ぶん名前付きの札＋太い進捗カプセル＋♥。ウマ娘も JRA も、絵の上は最小
6. 実況は箱2つ。順位表は 3px の色棒で、絵の中の札と記号がつながっていない

## 3. 案と、自分での批判

| 案 | 批判 | 判定 |
|---|---|---|
| A. 予想画面の地を無彩の濃灰に、カードは枠なしの一段明るい面に | 他の画面は青緑の世界。予想画面だけ灰だと別アプリに見える → **青緑をわずかに残した濃灰**（地 #0f1517 前後）にして世界とつなぐ | 採用（調整つき） |
| B. 予想画面の火の粉・光彩・グラデ・金枠をやめる | 火の粉はタイトル〜ホームの世界観の演出。全画面から消すのは越権 → **予想画面だけ**止める。金は「選んだもの・押すボタン」の2か所だけに残す（TIPSTAR の役割色の考え方） | 採用 |
| C. 竜の識別を「竜の色の丸札」に統一（出走表・スリップ・レース中の札・順位表・答え合わせ） | 丸札の中に何の数字を入れるか：出走表は人気順で並ぶので**人気番号**、レース中は**いまの順位**＝数字の意味が場面で変わる。JRA は馬番で固定。だが本作には馬番が無く、新しい番号を足すと「人気」「番」「順位」の3つが並んで混乱する → 丸札は**色が本体**、数字は「その画面の並び順」と決める（出走表＝人気、レース＝順位）。色の明るさで文字を白/黒に切り替えないと黄色や白系の竜で読めない | 採用（文字色の自動切替つき） |
| D. 数字を大きく、太さを中くらいに。細身の外部書体は使わない | 前回は根拠なく Barlow を足した。TIPSTAR も普通のゴシック。外部読み込みは通信と表示のちらつきの元 → 端末の書体のまま `tabular-nums`＋大きさで差をつける | 採用 |
| E. Smart View 式に、このコースの序盤・中盤・終盤で効く能力3つを出走カードに目盛りで出す | 情報は「▾見る」の中に既にある＝並べ替えだけ（Flatstudio の教え）。ただし**行に出すと勝ちやすくなり、ミズの分析予想（章で解禁）の価値と序盤の財布の釣り合いが変わる**。数値は不変でも難しさが変わる＝見た目の仕事の範囲を越える | **今回は入れない**（別途ユーザー判断） |
| F. レース中の名札を「自分の竜と先頭だけ名前つき、他は色の丸札だけ」に | 誰が誰か分からなくなる心配 → 下の順位表が同じ色の丸札＋名前で並ぶので、色で照らし合わせられる（JRA と同じ仕組み）。自分の竜を見失わないことが最優先 | 採用 |
| G. 進捗の帯を JRA/ウマ娘式に細く、竜の色の点で | 今の帯も点は竜の色。太いカプセルの外枠と背景板が古く見える → 板を外し、線と点だけに | 採用 |
| H. 区間の切り込み帯（斜めの帯＋流線）を変える | 区間に入る瞬間＝熱狂側の演出。ウマ娘のスキル演出も派手 → **変えない**（色だけ合わせる必要も無い） | 不採用 |
| I. 答え合わせ（結果） | 的中の瞬間＝熱狂の頂点。派手でよい場面 → 今回は触らない。地の色だけ予想画面に揃えるかは、作って比べてから | 保留 |

## 4. 決めたこと（今回作る範囲）
1. 予想画面：地・面・線・文字の強弱・数字（A・B・D）
2. 竜の色の丸札（C）：出走表・スリップ・順位表・レース中の札
3. レース中の絵の上：名札の整理（F）と進捗の帯（G）
4. 作ったあと、参照先と並べて撮り比べ、良い/悪いをこの文書の末尾に書く

## 5. 作ったあとの評価（2026-11-26・音を消した裏のブラウザで 390×844／360×640／PC枠470 を撮影）
良くなった：
- 予想画面は火の粉・紫・金枠・光彩が消え、TIPSTAR の「冷静」の側に寄った。金は選んだ竜・賭け金の選択・出走ボタンだけ
- 竜の色の丸札が、出走表（人気）→スリップ（色の点）→レース中の札→順位表（いまの順位）でつながった。レース中、絵の「8」と順位表の「8 シオ」が同じ色で一目で照らし合わせられる
- レース中の名前つきの札は自分の竜と先頭だけ。他は丸札だけになり、絵が見やすくなった。発走前は全員の名前を出す（紹介の時間）
- 進み具合の帯は背板と外枠を外して、細い線と点だけ

作って分かった失敗と直し：
- 竜の絵を黒い箱に入れたら切り抜き写真のように見えた → 箱をやめ足元の影だけに。すると頭が名前の行にかかった → 絵を枠の幅に収まる大きさに
- 「最大」が縦に折れた → 折り返し禁止
- PC枠で出走カードが2列に割れて崩れた（前から） → 1頭1行に固定

まだ古く見える所（調べてから決める・今回は触らない）：
- 共通ヘッダ（作品名・金のコイン札・ランク札）。全画面に出るので、この2画面だけ変えると画面ごとに食い違う
- レース中の全幅の帯（「隊列形成」「三つ巴！」「ゴール！」＝暗い帯＋金の2本線＋縁取り文字）。熱狂の場面の演出なので、今の中継・ゲームの山場の見せ方を調べてから
- 答え合わせ（熱狂の頂点）。地の色だけ揃えるかは保留
