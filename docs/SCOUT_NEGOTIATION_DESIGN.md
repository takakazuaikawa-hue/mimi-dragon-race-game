# 竜スカウト＝発見＆交渉ゲーム 設計書（⑤）

> 進行再設計 ⑤「竜スカウトのロケ段階解放＋マスク」を、**単純なミニゲームにせず**、
> モールの「大冒険（お買い物ダンジョン）」の“場を選んで潜る”構造だけ借りて、
> **まったく別の「発見＆交渉」ゲーム**として作る。
>
> 竜は**人語を話さない**。**しぐさ・行動**で気持ちを仕掛けてくる。プレイヤー（ミミ）は
> しぐさを**読み**、**数十通りの交渉術**から最適を選び、心を開かせて**全頭スカウト**する。
>
> ★絶対制約（[[race-math-immutable]]）：着順/オッズ/配当/出走表は一切不変。本機能は**表示専用メタ**。
> スカウト成立の払い出しは既存と同一（`collection[id].scouted/seen` ＋ `raiseAffection` ＋ `epPush("scoutNew")`）。

## 2. 交渉エンカウンター（核心ループ）

1頭の竜との 1 セッション。**発見 → 遭遇 → ラウンド制の読み合い → 成立／決裂**。

### 2.1 発見（discovery）
場に入る→「探す」。足跡・鱗・匂い…の痕跡演出を経て**遭遇**。出会う竜は
その場の未スカウト竜から**決定的**に選ばれる（全スカウト済なら「もう新しい竜はいない」）。

### 2.2 ラウンド制（読み合い）
竜の内部状態（**非表示**で進行）：
- **警戒（wary）** … 高いほど逃げやすい。気質で初期値が違う（気性難ほど高い）。
- **信頼（trust）** … 高いほど成立に近い。0スタート。`TRUST_GOAL=100`で成立。`WARY_MAX=100`で決裂。
- **心情（mood）** … 今この瞬間の感情。**しぐさで表現**（明示しない＝プレイヤーが読む）。

1ラウンド：
1. **竜がしぐさを見せる**（gesture文）。例：「ぐるるっ…と低く唸り、半歩あとずさった。」
2. **読み**（任意）：ミミの直感コメント＋〔観察〕で心情を明示化できる（後述）。
3. **交渉術を選ぶ**：手札（毎ラウンド回転する数枚）＋常設（観察／ぱほぱほ）。
4. **解決**：選んだ術 × 今の心情 で判定（§3）。竜の反応しぐさ＋ wary/trust が動く。
5. trust≥100→**成立**（心を開く演出→契約＝既存払い出し）。wary≥100→**決裂**（竜は去る・再挑戦可）。

### 2.3 心情（mood）＝10種・しぐさで表す

| mood | しぐさ例 | 効く交渉（要旨） | 逆効果 |
|---|---|---|---|
| 威嚇 | 牙をむく/翼を広げ大きく見せる | 引く・下手に出る・視線外す | 近づく・手を出す・見つめる |
| 警戒 | 横目で睨む/身を低く後退 | 動かない・小さくなる・待つ | 急接近・大声・掴む |
| 不安 | おどおど/尾を丸め震える | しゃがむ・ゆっくり瞬き・やさしい声・子守唄 | 距離取る・無視・大声 |
| 好奇 | 首をかしげ匂いを嗅ぐ | 手を差し出す・光り物・真似 | 睨む・伏せる |
| 甘え | すり寄る/喉を鳴らす | 撫でる・寝そべる・菓子 | 無視・後ずさる |
| 遊び心 | 飛び跳ねる/誘うように後退 | 遊ぶ・追いかけっこ・回ってみせる | じっと座る・真顔 |
| 誇示 | 胸を張る/翼を広げ美しく咆哮 | 褒める・見惚れる・真似る | 無視・同情・しゃがむ |
| 退屈 | あくび/そっぽ/地面を掘る | 光り物・遊び・珍しい動き | 待つ・沈黙 |
| 空腹 | 鼻をひくつかせ涎/物欲しげ | 食べ物・贈り物・果実・水 | 撫でる・遊ぶ |
| 眠気 | とろん/うとうと伏せる | 子守唄・静かに待つ・そっと撫でる | 大声・遊び・急接近 |

### 2.4 交渉術（approach）＝数十通り・7カテゴリ

`身`（姿勢）/`声`/`間`（距離・待ち）/`贈`（贈り物）/`真似`/`遊`/`技`。各 approach は
`helps:[mood…]` `hurts:[mood…]` を持ち、§2.3 の対応表を表現する。常設の特殊：
- **観察**：trust 不動。次のしぐさで**心情を明示**（読みのヒント）。何度でも。
- **ぱほぱほ**（ミミの汎用スキル）：強力な和ませ。wary 大幅減＋trust 微増。**1セッション1回**。
- **ポロに通訳**：ポロ同伴時のみ。現在の心情を読み解く＋微 trust（相棒の見せ場）。

手札制で「数十から選ぶ」感を出しつつ画面は数枚。全 approach は §3 の判定で**心情ごとに効果が変わる**ため、
「このしぐさは何の気持ち？→だからこの術」を当てる**読み合い**が成立する。

### 2.5 竜の個性（persona）＝全頭が違う交渉体験

`stats.nerve` ＋ `traits` ＋ id から**決定的**に導出：
- **初期警戒** … 気難しいほど高い。
- **心情分布（weights）** … 気性難→威嚇/警戒多め、素直/気性◎→好奇/甘え、華→誇示、眠→眠気、渋い/地味→退屈/警戒、ふらり/大穴/夢→きまぐれ（散らばる＝読みにくい）。
- **読みにくさ** … きまぐれ系はしぐさが心情とズレやすい（観察の価値が上がる）。
- **好物カテゴリ** … 当たり術が persona 好相性だと「大当たり」に昇格。

## 3. 判定（resolve）

```
mood ∈ approach.helps  → good（persona好相性なら great）   trust +12（great +20） / wary −10
mood ∈ approach.hurts  → bad                               trust −6  / wary +14
それ以外               → neutral                           trust +3  / wary +2（焦れ）
観察                   → reveal（次ラウンドの心情を明示）   増減なし
ぱほぱほ（1回）        → soothe                             trust +8  / wary −25
```
- 次ラウンドの mood は persona weights を基に、**wary 高→威嚇/警戒寄り、trust 高→甘え/遊び/誇示寄り**に補正して決定的抽選（seeded PRNG・Math.random不使用）。
- 成立 `trust≥100` ／ 決裂 `wary≥100`。ソフト上限 ~12 ラウンド（焦れで wary が必ず上がるので収束）。

## 4. 学習・コレクション（やり込み導線）

- 一度見たしぐさ／効いた術は**交渉メモ**に残る（「このしぐさは“不安”だった」）→次回から読みやすい。
- メモの充足＝交渉術の習熟＝🏆コレクション得点（[[ui_collection_score]]）の「スカウト」行に将来連動可。
- 全頭スカウト＝龍舎コンプ＝終章の絶滅メーター押し戻し（既存 `epPush("scoutNew")`）。

## 5. 実装フェーズ

- **Phase A（基盤＋ハブ）**：本書／`js/data_scout.js`（ロケ・心情・交渉術・しぐさ文・ペルソナ）／
  `js/scout_engine.js`（ロケ開放・竜割当・PRNG・セッション・rollGesture・resolveApproach・勝敗＝純ロジック）／
  `renderScout` を**ロケ段階ハブ（マスク付き）**へ刷新。発見→（暫定）契約は既存払い出しを場別に流用＝**常にプレイ可能**を維持。eval検証＋デプロイ。
- **Phase B（交渉UI）**：発見→遭遇→ラウンド制交渉画面（しぐさ表示・手札・判定演出・成立/決裂）。暫定契約を本交渉へ置換。
- **Phase C（磨き）**：読みヒント/交渉メモ/persona個性の体感差/しぐさ演出/バランス＋ビジュアル（スクショ復帰時）。
