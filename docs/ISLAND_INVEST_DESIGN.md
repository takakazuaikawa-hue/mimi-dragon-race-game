# 5章「島づくり」体験設計（正本）— ISLAND_INVEST_DESIGN

親：docs/GAME_EXPERIENCE_DESIGN.md（5章の核）・HUNGER_ECONOMY_DESIGN（コインシンク最終形）。
接続：epilogue_engine.js（絶滅メーター）・ui_economy.js（🏦島の経済）。
鉄則：レースの着順/オッズ/配当/FinalPower は不変。島投資＝コインシンク＋テキスト進化＋メーター押し戻し。

## ★ 設計の芯（レーダーは目的ではない）
5章の面白さは**「勝ち取った大金を島に注ぎ込むたび、島が目に見えて変わり、迫る絶滅を押し戻す手応え」**。
＝ **投資 → 島が変わる → 絶滅が退く** の1ループが体験の本体。
6角レーダーは「今どこが手薄か」を一目で示す**ダッシュボード（副）**であって、遊びの主役ではない。
だからUIの主役は「事業（プロジェクト）を選んで叶える瞬間」＝完成の一言＋島テキストの格上げ＋メーターが一段退く演出。

## 1. ★投資はレベル制（逓増コスト）＝プレイヤー心理の要
**まとまった一括購入は「先が見えず挫折」する**（例：6千万を一発は貧しい序盤に絶望を生む）。
アイドル/経営ゲームの鉄則どおり、**各施設をLv0→8へ少しずつ育てる**。設計原則：
1. **常に今すぐ買える次の一手**（安いLv1）2. **進捗が常に見える**（Lv3/8のバー）3. **逓増コスト**
（序盤安→終盤高＝収入の伸びと一致）4. **どこに注ぐか選べる**（手薄軸を補強）5. **少額でも積み上がる**
（無駄なし）6. **節目にご褒美**（名前つき変化＝ただの数字にしない）。

`ISLAND_FACILITIES`＝6分野＝6施設。各 `{ id, ic, name, color, maxLv, base, growth, milestones }`。
- **コスト** `cost(lv) = round(base × growth^lv)`（lv=現在Lv・0基点）。序盤2M級→Lv8で1億級。
- **1投資 = 1Lvアップ**：`cost` 消費 → Lv+1 → メーター押し戻し（通常Lv=小/節目Lv=大）→ 発展度+1。
- **milestones**（節目Lv）＝名前つき事業。`{lv: {name, react(語り手の一言), doom, evolve?}}`。
  節目に達すると完成カットイン＋島テキスト格上げ。通常Lvは「〜を少しずつ整備」＋軽トースト。
- **発展度** = 全施設Lv合計（最大 6×maxLv）。帯（芽/育/栄/極）が `islandTier()`。

| 施設 | 節目（Lv1/4/8＝安→高） | 育つと |

## 2. 綱引き（体験の緊張＝ドラマの難易度）
- 5章中、レースを走るたび絶滅メーターは +DOOM_PER_RACE 進む（既存 doomTick）。
- **島投資が最強の押し戻し**：事業完成で `epPush` 相当（meter -= project.doom）。
  ＝「私の稼ぎが、島の寿命を延ばしている」を数字とメーターで体感。
- **バランス＝島の底力（resilience）**：6分野の投資が偏ると弱点をつかれる。全分野に手が回るほど
  `resilience` が上がり、doomTickの進みが緩む（受動ボーナス）。**レーダーはこの偏りの可視化**。
- 難易度は「怠ると苦しく、バランス投資すれば間に合う」調律（数値はGAME_DESIGN_NUMBERSへ集約・実プレイ調整）。

## 3. 発展度と歩ける報酬
- **発展度** = 完成事業の重み合計。帯（芽/育/栄/極）で `islandTier()` を返す。
- 帯が上がると島じゅうのテキストが進化（`evolve` 台帳＝観光line→食note→村人→景況）。
  ＝投資の報酬は「数字」ではなく「歩いて確かめられる島の変化」。これが5章の醍醐味。

## 4. 最終決戦の結線（終局）
勝利条件＝積んだ全部が揃う（既存要素の合流・新規最小）：
①8龍集め（スカウト＝竜分野と連動）②島の発展度が閾値（島投資の成果）③5顧問の助言（神眼）
④伏線回収（物語フラグ）→ 4条件チェックリストを最終決戦前に提示＝「今までの全部で勝つ」カタルシス。

## 5. 3点セット（拡張契約）
- **駅**：🏝島時間に「🏗島づくり」（島の経済画面内・5章解放）。
- **発見**：5章マス（新行動＝事業に投資／新反応＝島テキスト進化＋メーター押し戻し）。
- **結線**：レース結果の余剰コイン→「島に投資する」NEXT_SUGGEST（5章時）＋発展の節目で日報記事。

## 6. 実装ウェーブ（体験の核から）
- **I1 投資ループ（体験の本体）**：island状態（invested集合／分野別投資度／発展度）＋
  🏗島づくり画面（分野別に事業カード・cost明示・叶えるボタン）＋叶える＝コイン消費＋
  epPush（メーター押し戻し）＋完成の一言（react）＋発展度再計算＋景況文が発展度で変わる（evolve初弾）。
  6角レーダーは画面上部の“手薄マップ”として添える（副）。
- **I2 テキスト進化の量産**：evolve台帳を観光line→食note→村人へ薄く広げる。
- **I3 バランス→resilience→doomTick緩和**（綱引きの調律）。
- **I4 最終決戦チェックリスト**（4条件・既存フラグを読むだけ）。
※4章側（スマホ/スカウト/シェア→フォロワー/条件解放の食事）は既存が大半＝別途E4系で締める。
