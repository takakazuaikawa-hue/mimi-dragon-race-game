# 島投資システム 設計（正本）— ISLAND_INVEST_DESIGN

親：docs/GAME_EXPERIENCE_DESIGN.md（5章の核）・docs/HUNGER_ECONOMY_DESIGN.md（コインシンクの最終形）。
既存接続：js/ui_economy.js（🏦島の経済＝ここに同居）・epilogue_engine.js（絶滅メーター）。
鉄則：レースの着順/オッズ/配当/FinalPower は不変。島投資＝表示専用メタ＋コインシンク＋テキスト進化。

## 0. 体験の狙い
「稼いだ大金の使い道」の最終形。**島を自分の手で育てる**手応え＋**絶滅メーターとの綱引き**の緊張。
発展に応じて島じゅうのテキスト（スポット/食べ物/村人）が変わり、育つ実感を文章で味わわせる。

## 1. 6分野レーダー（産業バランス）
`state.player.island = { infra, commerce, race, dragon, public, industry }` 各 Lv 0〜10（initガード）。
| 分野 | アイコン | 投資先の例 | 上げると |
|---|---|---|---|
| 🏗 施設(infra) | 道・港・橋 | 観光の移動快適／新スポット解放 |
| 🏪 商業(commerce) | 店・市場・モール | 買い物の品揃え／お土産の種類 |
| 🏟 レース(race) | レース場・馬場 | 開催格の上限（G3→G1）・観客 |
| 🐲 竜(dragon) | 宿舎・牧場 | スカウト成功率演出／竜の福祉テキスト |
| ⛲ 公共(public) | 学校・病院・広場 | 住民の幸福／村人コメントが明るく |
| 🏭 産業(industry) | 農・漁・工房 | 食材の質＝上級グルメ解禁／自給 |

- **6角レーダーグラフ**で可視化（SVG・ui_economy内）。**バランス型が最も伸びる**：
  総合発展度 = Σ(Lv) × バランス係数（最小Lv/最大Lv が高いほど係数UP＝偏りペナルティ）。
- 投資コスト＝`分野Lv+1 の階段価格`（例 Lv1=10万, Lv2=25万…指数）。稼ぎの大出口。
- **表示専用**：レース結果には無干渉。総合発展度は「島の景気ティア」の表示を補強するだけ。

## 2. テキスト進化（発展の醍醐味）
発展度の帯（低/中/高/極）で、既存のテキスト差し替え台帳を切り替える：
- 観光スポットの `line`（§KM）／食べ物の note ／村人コメント ／聖龍日報の景況。
- 実装＝各データに `evolve: { mid, high, peak }` 任意フィールド（無ければ既定文）。
  `islandTier()` が現在の帯を返し、描画側が evolve[帯] を優先。**1フィールド追加で1か所が育つ**。

## 3. 絶滅メーターとの綱引き（ドラマの難易度）
- 5章中、絶滅メーターは進み続ける（既存 epilogue）。**島投資が防波堤**：
  総合発展度が高いほどメーターの進行が緩む（表示上の係数・最終決戦の到達しやすさを調整）。
- 「投資して島を富ませる＝淘汰に抗う」が物語＝経済の一致（PARIMUTUEL_ORACLE_VS_HOUSE の思想）。
- 難易度は**ちょうどよくクリアへ**：発展を怠ると苦しく、バランス投資すれば間に合う調律
  （数値は GAME_DESIGN_NUMBERS に集約・後で実プレイ調整）。

## 4. 最終決戦の結線（終局）
勝利条件＝4つの伏線が揃う（既存要素の合流・新規最小）：
1. **8龍集め**（スカウト＝dragon分野と連動）
2. **島の経済**（総合発展度が閾値＝island投資の成果）
3. **5顧問の助言**（サケ/ミズ/スミカ/マクラ/セレスティア＝神眼コンサルト）
4. **伏線回収**（物語フラグ）
→ 4条件のチェックリストを最終決戦前に提示＝「今まで積んだ全部で勝つ」カタルシス。

## 5. 3点セット（拡張契約）
- **駅**：🏝島時間に「🏦島投資」を追加（島の経済画面内タブ／5章解放）。
- **発見**：5章マス（新しい行動＝バランス投資／新しい反応＝テキスト進化）。
- **結線**：レース結果の余剰コイン→「島に投資する」NEXT_SUGGEST（5章時）。還流＝発展の節目で日報記事。
