## §7 エリアを増やすときの背景の作り方（2026-08-01・実証済み・**次はここから読む**）

### ❌ やってはいけない：文章プロンプトでゼロから描かせる
`docs/POLISH_DIRECTIVE.md` §1 のレシピ（`Top-down three-quarter overhead ...`）を土台に
3バッチ12枚生成したが、**全部アイソメトリック（斜め45度）**になり1枚も使えなかった。

**真因は "three-quarter" という語**。地形だけのエリア（race/onsen/beach）では無害だったが、
**建物が密集する街区では斜め視点の指示として支配的に効く**。
`NOT isometric` と否定を足しても、参照画像を渡しても効かなかった。

### ✅ 正しい手順：**既存マップの隣を継ぎ足させる**（outpaint 方式）
同じ絵の続きを描く以外に選択肢が無くなるので、**投影・縮尺・画風・パレットが構造的に揃う**。

1. **キャンバスを作る**（`sharp`）：既存の隣接エリア画（1920×1440）を左に置き、
   右を無地で埋めて **ちょうど 21:9（3360×1440）** にする。半端な比だとモデル側で
   リサイズされて位置がずれる。
2. `media_upload` → curl PUT → `media_confirm` でアップロード。
3. `generate_image` に **`model: "nano_banana_pro"` / `role: "image"`**（`image_references` は不可）/
   `aspect_ratio: "21:9"` / `resolution: "2k"` / `count: 2`。
   プロンプトは「左は完成済み、**右の空白だけを埋めろ**、左は一切変えるな」＋新エリアの内容。
   ★`seedream_v4_5` は `image_references` を受けるが**継ぎ足しには効かない**（実測）。
4. 返るのは 3168×1344（元の0.943倍）。**右端から 4:3 を切って 1920×1440 へ拡大**する。
   重なりは既存エリアの外周（林や壁）だけにする＝内容が二重に写らない。
5. **32×24グリッドを重ねた画像**を出してコリジョンを起こし、**赤塗りオーバーレイ**で突き合わせ。
   ★`sharp` の合成は「等倍で composite → 別途 resize」の順でないと
   `Image to composite must have same dimensions or smaller` で落ちる。
6. `tools/check_walk.mjs` で BFS 全緑＋接続グラフ連結＋片道なしを確認。

**費用の実績**：失敗12枚を含めて計14クレジット（640→626）。継ぎ足し方式だけなら2クレジット。
