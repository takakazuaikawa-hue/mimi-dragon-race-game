## §0 不変条件（先に固定）
- **計算式は一切変えない**：資産6成分・名声式・印税式（読者×(0.5+2×収集率)＋資産×0.1%×(1+景気)）・
  ED=10億・3本レール・レース数値。変えるのは**いつ・どう見せて・どう教えるか**だけ。
- 進行判定は assetsPeak のまま。内部では1話から資産が積まれ続ける（見せないだけ）。
  → 開放イベントの瞬間に「積んできた値が初めて開示される」＝サプライズとして機能する。

## §1 概念の一枚図（用語の正本・画面もこの語彙に統一）

```
🪙 コイン ＝ いま使えるお金（賭ける・買う・食べる）
   │  勝てば増え、負ければ減る。ゼロなら無心。
   ▼
📖 印税 ＝ 毎日入りつづけるお金（コインとして届く）
   │  源泉は「経験の記録」：読者数 × 記録の充実度（図鑑・写真・食べ歩き・思い出）
   │  ＋ 資産の実り（資産×0.1%〜）。※現行のログインボーナスの正式名称
   ▼
🏦 資産 ＝ ミミの積み上げた価値の評価額（現金ではない）
   │  ＝ 暮らし（家・服・道具）＋ 名声 ＋ 図鑑の記録 ＋ 村 ＋ 島への投資
   │  物語の関門（3万→100万→…→10億）はこれの到達最高で開く
   ▼
✨ 名声 ＝ ランク・勝利・大勝から自動で積もる評判（資産の一部）
🌱 暮らしLv ＝ 資産段位で上がる生活の豊かさ（くらしツリーで上限が伸びる）
```

**禁止語**：「村レベル」（暮らしLvに一本化済みのはずが表示に残骸あり→掃除）。
「ログインボーナス」（→「今日の印税」に改名）。

## §2 診断（なぜ初見で意味不明か）
1. **資産が最初から見える**：未勝利でもランク2昇格で名声8000、図鑑自動登録で1500×N…が
   説明なく合算され「4.12万」と表示される。プレイヤーは自分が何をしてその数字になったのか
   一度も教わっていない。
2. **語彙が画面ごとに揺れる**：村レベル残骸／暮らしLv／景気ティア／名声——同じ画面に
   未紹介の概念が4つ並ぶ。
3. **印税の物語が切れている**：収入は「ログインボーナス」の顔で届き、紀行（ブログ）の
   売上・読者数と心理的に結線されていない。「経験が印税になる」実感が無い。

## §4 説明イベントの台本骨子（褒めながら開く・声表準拠）

**A. スミカの家計簿（第3話前半・暮らし開放）**

- ミズ「気づいてないの？ あなた、もう**値がついてる**のよ」

  それが『資産』。**物語はこの数字で先へ進む**わ」

**C. マクラの印税講座（第4話・印税開放）**
- マクラ「ミミさん、毎朝入ってるお金、あれ何か知ってます？ **印税**ですよ。
  紀行の読者が、ミミさんの記録を読みに来てる」

- 以後、受取ポップの名前を「📖 今日の印税」に変更し、内訳（読者/充実度/実り）を一行ずつ出す。

## §5 くらしツリー＝ギャグカットイン取得
ユーザー決裁：「イベントの所々でカットインで取得していくのがギャグとして面白い。
**手で取るだけのものにしない**」

- 方式：**イベント連動の自動取得**を主経路に。食事・観光・物語の区切りで、文脈に合う
  ノードが**バーン**と入る（例：食べ歩き5品目の直後に「🌱『台所の勘』を会得！」）。
- カットインの型：全画面フラッシュ＋ノード名＋一言ギャグ（0.9秒・タップで即closable）。
  progression の cut-in とは別の軽い型（毎回モーダルだと重い）。
- 手動取得も残す（P残の使い道・好きな人向け）。自動はイベント文脈に合うノードのみ。
- **要対応表**：どのイベントがどのノードを射抜くか（＝R5の決裁事項と同一。約20対応を
  実装前にユーザーに一覧で出して決裁）。

## §6 紀行の実感成長（読者数・売上の差異への回答）
- 読者数＝フォロワー式（800＋名声×2＋完走×15＋勝利×40）→ **増えた瞬間に理由つきで見せる**：
  紀行を開いたとき前回比を「👀 読者 +55人（勝利のニュース +40／完走 +15）」と1行で。
- 累計売上＝印税の積算（式は不変）。「今日の印税」内訳と同じ語彙で並べる。
- 紀行の各記事カードに「この経験で読者が増えた」目印（表示専用）。
- ★計器にしない：グラフ・残り・目標％は置かない。**増えた瞬間の理由**だけを言う。
