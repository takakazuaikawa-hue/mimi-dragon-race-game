## 1. 三本柱

### 柱A 『ドラゴンレース紀行』作者システム（序盤〜・経済の背骨）

**設定**：第1話でサケに勧められ、ミミは島の見聞録『ドラゴンレース紀行』を書き始める
（＝ゲームタイトル「ミミのドラゴンレース紀行」の回収。プレイヤーが遊んだ記録＝紀行そのもの）。

- **売上（印税）**：毎日ホームで受け取る収入。現行ログボを改名・式を置換する。
  ```
  きょうの売上 = base × (1 + 紀行の充実度) × 景気ティア係数 × 7日サイクル倍率（既存[1→7]）
  紀行の充実度 = 既存カウンタの合成（図鑑seen・食べ歩き・写真・観光スポット・スカウト成立・
                衣装・小イベント既読…）＝ ui_collection_score の総合達成度をそのまま使う
  ```
  - **島をめぐるあらゆる行動が売上を押し上げる**：食べる→食レポが増える→売れる。
    スカウト→竜の記事が増える→売れる。観光・買い物・写真も同様。
  - 序盤は小遣い（数百〜数千）、終盤は達成度×資産で数百万〜1000万級＝
    「資産が働く」感（v1の雪だるま）はこの式が自然に担う。
  - UI：受け取りモーダルに内訳（📖記事の充実 ×◯％／💗人望…）を出して「行動が資産になる」を見せる。
- **人望**：既存フォロワー（800+名声×2+完走×15+勝利×40）を売上式の係数に結線（表示専用のまま）。
- 実装は**表示メタのみ**：既存カウンタを読む・コインを足す・レース数値に非干渉。

- 5章の流れ：1億で5章 → 島づくり（投資=資産）＋紀行の売上で**10億へ資産形成** → 神眼レース解放。
  複利の速い人は早く着くが、**最後の壁（柱C）はお金では抜けられない**ので5章の芯は保たれる。

### 柱C 神眼レース（最後のイベントレース・ゲームクリア）

**物語**：セレスティアの神眼は「決着」を見通す。ならば**決着そのものを消す**——
3頭が寸分違わず同時にゴールすれば、神眼は何も読めない。何日も能力表とにらめっこした
**寝不足ミミの赤目**が、神眼を打ち破る（クリア一枚絵）。

**仕様（案）**：
- **解放**：第5話既読 ∧ 総資産（到達最高）10億。
- **出走**：最高クラスの8頭（案：八竜集結の8頭＝スカウトで縁を結んだ竜たち。要決裁）。
- **訓練**：レースの前に各頭の能力（スタート・登り・降り・スパート等）を**上げ下げ両方**できる
  （下げられるのが鍵＝エースを抑えて3頭を揃える）。訓練ptは紀行の売上/島の行動で獲得。
- **レース**：**能力だけで決まる**決定的シミュレーション（乱数なし・「その日の風」程度の固定微差のみ）。
  賭け・オッズ・配当は**存在しない**＝既存エンジンに触れない独立モード。
- **試走**：何度でも走らせて着差を観察（「2着と3着の差 0.31秒」）→ 能力を調整 → 再挑戦。
  **着差のフィードバックを頼りに3頭を収束させるパズル**。
- **クリア判定**：上位3頭のゴール時刻が許容差（例：表示上の同着＝内部0.05秒）以内。
- **クリア**：赤目ミミの一枚絵 → `edFlag` → ED解放（以降のエンディングは既存のまま）。
- 既存の終章（絶滅メーター綱引き→最終決戦）との接続：**最終決戦の中身をこのレースに置き換える**案を推奨
  （メーターは道中の演出として存続）。ここは実装時に既存演出を読んでから最小の縫い直しを提案する。

**難しさの見立て（ユーザーの質問への回答）**：実装可能。核は
①新しい小さな決定的シム（既存の race_engine とは別・能力→区間タイム→合計）
②訓練UI（8頭×能力スライダー＋試走ボタン）
③同着判定と演出。
規模感は「しのびあし」級の新ミニゲーム＋既存レース描画の流用。**一番の設計点は
「同着の許容差」と「調整の手応え」**（簡単すぎ＝3頭同値にして終わり、を防ぐため、
能力→タイムの写像を区間ごとに非線形にし、試走の反復で詰める作りにする）。

## 2. 想定される終盤の体験

```
1億で5章 →『紀行』が売れ始める（行動↑=売上↑）→ 島づくり投資（資産に計上）
 → 資産形成いろいろ（投資・食べ歩き・写真・スカウト＝ぜんぶ紀行のネタ＝ぜんぶ資産）

 → 8頭の能力表とにらめっこ。訓練で上げ下げ→試走→着差を見る→また調整…（寝不足）
 → 3頭同着！ 神眼、沈黙 → 赤目ミミの一枚絵 → ED
```

## 3. 決裁結果（2026-07-30・ユーザー回答）

1. **8頭の顔ぶれ＝固定メンバー**。神眼レースの画面で「この竜のスカウトが必要」と**明示**し、
   スカウト成立後に育成（訓練）できるようになる（＝スカウトが終盤の必須コンテンツに昇格）。
   具体的な8頭の人選はM3の設計時に提示して決裁を仰ぐ。
2. **4章の面白さを潰さない**（決裁条件）：M1では4章以前のゲート・収入に一切触れない。
   島づくりは終章解放のまま・ランク①②レール不変・救済Lv7以下不変。
   実装後に回帰シミュレーションで「100万・1億への到達レース数が従来と同等」を機械確認する。
3. **実装順OK**：M1 柱B（数値）→ M2 柱A（紀行売上）→ M3 柱C（神眼レース）。

### M3 追補：最終決戦の一枚絵 2枚体制（2026-07-30）
神眼レースの山場に、勝ち／負けの**両方**に一枚絵を置いた。素材は Higgsfield `seedream_v4_5` + `quality:"high"`。

| 場面 | 画像 | 発火条件 | キャプション |
|---|---|---|---|
| クリア | `images/story/shingan_clear.webp` | 上位3頭の差 ≤ 0.10秒（初回） | 三頭同着。——絶滅の神眼は、視るべき決着を失った。 |
| 惜敗 | `images/story/shingan_fail.webp` | 上位3頭の差 ≤ 1.00秒（`sg.failShown` で**一度だけ**） | 届かない。——叫びは光になっても、決着は、生まれてしまう。 |

- `_sgKeyVisual(kind)` を `SG_KV` 表で clear/fail の2種に一般化。惜敗版は CSS `.sg-kv.fail` で
  閃光を弱く短く（`sgKvFlashCold`）・地色を黒寄せ・キャプションを白銀にして「冷たい」画面にした。
- **毎回は出さない**のが要点。試走は何度でもできる画面なので、本当に手が届きかけた最初の1回だけ。
  以降は通常の結果行（`.sg-sp`）に戻る。惜敗VN（マクラ「決着です」→セレスティア「視えた」→
  ミミ「もう少しなんです」→「まだ寝ません」）のあと画面へ復帰＝**進行を止めない**。
- 表情に `sad` は存在しない（`buniqro`/`dragonrobe`/`newspaper` 以外は404→`smile`に落ちて真逆の顔になる）。
  惜敗のミミは `panic` を使う。
- 実測：0.44秒の惜敗で発火／画像760×1140でアスペクト差0／カード→VN→画面復帰／2回目は非発火。
