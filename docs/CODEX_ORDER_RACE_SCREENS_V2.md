6. 画面の確認は**音を消す**（Playwright を `--mute-audio` で起動）。BGM を鳴らさない。
7. ユーザー向けの文はすべて日本語で書く。

## 3. まだできる品質アップ（優先順・それぞれ「なぜ」と「できあがりの条件」つき）

### A. 先にやるべき（壊れ・実機の問題につながる）
1. **スマホ実機での確認**（iPhone の Safari と Android の Chrome）
   - なぜ：ここまでの確認は PC 上の裏のブラウザだけ。`:has()`（iOS 15.4〜）・`color-mix()`（iOS 16.2〜、3か所）・`backdrop-filter` を使っている。古い端末では `color-mix` の行が無視されて、地域色のにじみ・選んだカードの金の下地が出ない（壊れはしない）。
   - できあがり：両方の実機で、予想→レース→答え合わせを1周。崩れ・はみ出し・押せないボタンが無い。古い iOS 向けの代わりの色を `color-mix` の直前に1行ずつ足す。
2. **走る絵を縦に伸ばしたぶんの重さ**
   - なぜ：絵の高さが約480px → 最大約790px になり、塗る画素が約1.6倍。以前「熱」を理由に解像度を2倍までに抑えた経緯がある（`resize()` のコメント）。
   - できあがり：低めの Android で1レースを通し、コマ落ち・発熱を見る。重ければ、絵が高い時だけ解像度を 1.5 倍に下げる。
3. **淡い文字の読みやすさ**
   - なぜ：補足の文字色 `--cs-mute #6f7b7f` はカード `#182023` の上でコントラスト約3.7:1。小さい文字の目安 4.5:1 に足りない。
   - できあがり：`--cs-mute` を明るくし（目安 `#86929a` 前後）、4.5:1 以上を測って確かめる。

### B. 見た目の仕上げ（予想画面）
4. **相談役の4つの札**（分析予想・ドラゴン情報・財政状況・1着を聞く）が、まだ前の作り（2×2 の四角い札＋丸い記号）。開いた中の出走表だけ直した。→ 1行ずつの並び（記号・名前・ひとこと・▸）にするか、調べてから決める。
5. **人気の丸札の意味**：出走カードの丸札の数字が「人気」だと、初めての人には分かりにくい（「人気」の小さな字は、絵に重なるので外した）。→ 一覧の見出し（「1着になる本命を1頭タップ」の行）に「人気順」と添える等。
6. **ワイドの時のオッズ**：単勝・複勝は今の賭式の札だけを大きく出すが、ワイドは2つの数字が同じ大きさで並ぶだけ。→ 1頭目を選んだら、相手ごとのワイドの倍率を出す等（`betOdds` で読める。計算は変えない）。
7. 上の帯の地域色のにじみが、地域によっては茶色く濁る（`.bd-head` の `color-mix`）。地域ごとに撮って確かめる。

### C. 見た目の仕上げ（レース画面）
8. **区間に入る瞬間の斜めの切り込み**（`S.terrainSign`）は前のまま（熱狂の見せ場として残した）。山場の帯（箱なし・影の文字）と並べると作りが違って見える。→ ウマ娘のスキル演出など今のゲームの切り込みを調べてから。
9. **絵の上に浮かぶ短い文字**（「接戦！」「速さが得意！」「がんばれ！」）が、縁取りの太い文字のまま。山場の帯と同じ「影だけの文字」にそろえる。
10. **発走前の順位の塔**は5行（上位3頭＋賭けた2頭）になり、絵の左上を広く隠す。発走前だけ畳む等。
11. 順位が入れ替わる瞬間、塔の外れた行が「ほか4頭　タップで全頭」の帯に一瞬重なる（`boardSlotMap` で外れた行が待つ位置）。
12. 右の字幕が空の時の「……」が、作りかけに見える。

### D. 見た目の仕上げ（答え合わせ・全体）
13. **共通ヘッダ**（作品名・金のコイン札・ランク札）が、ホームと答え合わせでまだ前の作り。全画面に出るので、変えるならホームの作り（`docs/HOME_BG_SPEC.md`・TikTok ライブ風）と合わせて調べてから。
14. 答え合わせのタブの中（払い戻し・勝負所・実況ログ）は、色をそろえただけで中身の見せ方は見ていない。「結果」タブの着順の表にも竜の色の丸札を入れると、掲示板とつながる。
15. 読みの手帖の札（`.rj-result`・紫のグラデ）が答え合わせの中で浮いている。
16. **`race_screens.css` を `style.css` へ畳む**（いずれ）。今は上書きを重ねた層なので、同じ部品の指定が2〜3か所に分かれている。畳む時は `tools/check_ui_tokens.mjs` の数を増やさないよう、色・角丸・余白はトークン（`--cs-*`／`--r-*`／`--pd-*`）で書く。
