# 進行・物語の設計（決定版） — 何をして・何が解放され・何ができて・どうなるか

リリース前の確定設計。**全機能は表示専用/ゲートのみ＝レースの着順・オッズ・配当・FinalPower は不変**
（唯一の例外＝神眼コンサルトの「1着＝単勝1.1倍保証」。[[race-math-immutable]]）。
関連：docs/HOME_BG_SPEC.md（背景）・docs/PARIMUTUEL_ORACLE_VS_HOUSE.md（思想）・docs/epilogue_extinction_design.md（終章）。

## 0. 背骨

借金まみれのバニー・ミミが **「生き延びる → 予想を覚える → 暮らしを立てる → 配信者として羽ばたく → 島を守る」**。
この成長を **ホームそのものの変化**（静かな生活ホーム → 配信ホーム）で見せる。

物語＝経済の一致：セレスティア（予言者＝淘汰）が「答えを1点」に集めて賭場を壊そうとし、ミミと4顧問が
スカウト/暮らし/買い物/評判で「価値を1点に定めない構造（分散）」を作って賭場を守る。

---

## 1. ★ホームの2モード（最重要・新規）

| | 静かモード（序章〜第3話） | 配信モード（スマホ購入後＝第4話〜） |
|---|---|---|
| 立ち絵ミミ | ◯（独り言・タップ反応・アイドル演出） | ◯（同上＋ギフト/ハート演出） |
| 背景 | ◯（縦構図） | ◯ |
| 🎯目標チップ | ◯ | ◯ |
| レースへ進む／ナビ | ◯（暮らし/物語/設定/食事…） | ◯（＋📱SNS） |
| 下部の会話欄 | **🏘️村の人と会話**（近所の人がミミに話しかける・アンビエント） | **👥視聴者コメント**＋💬コメント入力＋❤️いいね |
| LIVE/👁視聴者/💗フォロワー | **非表示** | **表示** |
| 入場通知/🎁ギフト/SNS | **非表示** | **表示** |

**変身トリガー＝「📱スマホを買う」イベント**（第4話マクラの文脈）。マクラ（配信者）が「配信やってみな」と
背中を押す → ミミがスマホを購入（`phoneBought` フラグ）→ ホームが放送化＋SNS解禁。
＝プレイヤーの能動的アクションで世界が変わる（＋コインのシンク）。フラグ一本で `if (broadcastOn())` 分岐。

静かモードでも寂しくしない：**村の人の声**（`_addCm` を「村人」フレームで流用）＋ミミの独り言＋背景＋目標。

## 3. 目標(クエスト)＝解放のドライバー（goals.js を貼り直す）

★決定：**解放は「目標」に紐づける。各目標は条件（両フラグ）を明示し、達成で機能を解放**＝総資産しきい値と
章既読をAND表示するのでソフトロックも「次に何を」も解消。`nextGoal()` がそのまま導線。

| Ph | 目標 | 条件（明示する両フラグ） | 達成で解放 |
|---|---|---|---|
| 1 | はじめて出走 | completedRaces≥1 | — |
| 1 | はじめて的中 | everHit | 🐉図鑑（見る） |
| 1 | はじめて勝つ | wins≥1 | — |
| 1 | 屋台のごはん | lifeStage≥1（基本食事） | — |
| 2 | オッズを学ぶ（第2話） | 総資産≥3千 ∧ `_chapter_intro_2` | 🛍️モール買い物 |
| 2 | ワイド/複勝を当てる | firstWideHit | — |
| 2 | ランクを上げる | rank≥2 | — |
| 3 | 暮らしを立てる（第3話） | 総資産≥3万 ∧ `_chapter_intro_3` | 🛒モール拡張・🌱くらしツリー・生活資産 |
| 3 | 相棒を見つける | wins≥2（ポロ発見） | 🐲龍舎・🔭スカウト（序盤ロケ） |
| 3 | くらしツリーを育てる | lifeNodes≥1 | — |
| 4 | マクラに会う（第4話） | 総資産≥100万 ∧ `metMakura` | 📖図鑑の深い情報 |
| 4 | **スマホを買って配信開始** | `metMakura` ∧ `phoneBought` | 📱**配信ホーム・SNS・フォロワー・コメント** |
| 4 | フォロワー1万 | followers≥10000 | — |
| 4 | 新たな地でスカウト | 中盤ロケ解放（火山/崖/水中） | スカウト中盤ロケ |
| 5 | 神眼に出会う（第5話） | 総資産≥1億 ∧ `_chapter_intro_5` | 🌌絶滅メーター |
| 5 | すべてを解き放つ | 全開放トリガー | スカウト全ロケ・買い物全品・暮らし全枝・上級グルメ |
| 5 | フォロワー10万 | followers≥100000 | — |
| 5 | 島を守りきる | epilogue.edFlag | ED→クリア後コンテンツ |

※衣装「着替え」目標は、序章に**無料衣装を1〜2着**持たせる（モールは2話なので）か目標を2話へ。

## 4. 竜スカウト＝早期解放＋ロケ段階マスク

★決定：スカウトは**第3話（2勝・ポロ）で早期解放**。場所(ロケ)を段階解放し、未開放は枠内で**マスク（？？？）**。

| ロケ | 解放時期 | 雰囲気 |
|---|---|---|
| 🌾 草むら | 序盤（スカウト解放と同時） | 最初の出会い |
| 🌳 密林 | 序盤 | 鬱蒼・珍しい竜 |
| 🪨 崖 | 中盤 | 高所・気性荒い |
| 🌋 火山地帯 | 中盤 | 灼熱・力自慢 |
| 🌊 水中 | 中盤〜終盤 | 幻想・スタミナ |
| ☁️ 空中 | 終盤（終章） | 伝説格 |

各ロケに出る竜は固有。**スカウトした竜は表示専用＝出走しない**（着順に非干渉）。ロケ解放は総資産/章/勝利で。

## 5. 各システムの早期/全開タイミング（確認済）

- **暮らし画面（総資産ダッシュボード）**：早期から（根幹）。ゲートは**くらしツリー/生活資産の枝が第3話〜**。
- **龍関連**：序章的中＝**図鑑(見る)**／2勝＝**ポロ・龍舎・スカウト(序盤ロケ)**／第4話＝図鑑の深い情報／終章＝スカウト全ロケ。
- **食事**：基本は早期、**上級グルメは終章**（ティアでマスク）。
- **モール買い物**：第2話開始 → 第3話品目増 → 終章全品。
- **お買い物ダンジョン(mall_rpg)**：モール解放後。
- **クリア後**：ポロのグルメレース・エンドレスタワー＋各コレクションのコンプ＝得点/やり込み。

## 6. 実装順（提案）

1. **ホーム2モード化**（`broadcastOn()` ゲート＝`phoneBought`。配信UI群を分岐／静かモードに「村の人と会話」欄）＝最大。**直前のレイアウト調整を静かモードで再検証**（立ち絵足元・メニュー）。
2. **スマホ購入イベント**（第4話の文脈・購入で `phoneBought`→配信化の一幕/カットイン＋4話本文に一行）。
3. **目標(goals.js)のフェーズ貼り直し**＋各目標が「両フラグ＋達成で解放」になるよう解放ゲートを目標連動に。
4. **機能ゲート差し替え**（モール=2話/図鑑=的中/くらしツリー=3話/…＝総資産しきい値AND章既読）。
5. **竜スカウトのロケ段階解放＋マスク**（早期解放・序中終でロケ追加）。
6. **終章の全開放**（スカウト全ロケ・買い物全品・暮らし全枝・上級グルメ）。
7. **クリア後コンテンツ**（コレクション・コンプ得点の整備）。

## 7. 鉄則（変えない）

- レースの**着順・オッズ・配当・FinalPower・抽選**は不変（race_engine/odds_engine/betting_engine）。
- 上記すべては**表示専用/ゲート**。総資産・暮らしP・フラグを**読むだけ**。race計算を逆算しない。
- 神眼コンサルトの 1着＝単勝/複勝1.1倍保証だけが「意図された例外」（任意・1レース・着順不変）。
