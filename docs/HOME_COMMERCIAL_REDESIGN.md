# ホーム商業レベル化 設計書（正本）— HOME_COMMERCIAL_REDESIGN

目的：ホームを「触りたくなる商業モバイルゲームの顔」へ。ヘッダー/フッター含む情報再整理と
ナビ統合。配信風の個性（大立ち絵・LIVE・コメント）は本作の武器なので**捨てずに磨く**。

## 1. リサーチ（実在設計の原則）
- **ウマ娘のUI設計**（Game Watch開発者記事）：画面は「ヘッダー=全体状態／サブ情報=キャラ+
  コメント／メイン情報=主要数値+メインコマンド／フッター=補助」の4層。根幹は
  **「情報整理→表示のルール化」**＝機能ごとに表示ルールを固定し一貫させる。
- **モバイルゲーム一般**（Appnality/Justinmind等）：高頻度機能は1〜2タップ以内。
  **底部固定バーは3〜5アイコン**。関連機能はグルーピング。視覚階層（大きさ/コントラスト）で
  「何が押せるか・何が緊急か・次に何をするか」を一目化。
- **崩壊スターレイル**：メニューは3階層（ポップアップ／透過オーバーレイ／別画面）＝
  軽い機能ほど軽い表示で出す。

## 3. 新IA（ウマ娘4層×底部5タブ）
```
┌ ヘッダー（全体状態）────────────────┐
│ プロフィールピル(ランク/称号/連勝) ・ 🪙コイン ・ 🔊 ・ ⋯(設定/シェア/ヘルプ) │
├ ヒーロー（サブ情報・配信の個性はそのまま）──┤
│ 大立ち絵 / LIVE・視聴・フォロワー / 🎯目標チップ │
│ コメント流し＋コメントする＋❤️（ミッション帯はコメント上の1ピルに統合） │
├ メインコマンド ────────────────────┤
│ 🐲 レースへ進む（大CTA・唯一の金色）        │
├ フッター＝固定タブバー（5枠・safe-area対応）─┤
│ 🏝島 ・ 🌳暮らし ・ 🐲レース(中央大) ・ 📖図鑑 ・ 📱SNS │
└──────────────────────────────┘
```
**統合の中身（10→5+ヘッダー⋯）**：
- 🏝島＝観光マップハブへ（**食事・モール・龍舎/スカウトはハブ内ポータル済み**＝2タップ維持）
- 🌳暮らし＝暮らしハブへ（経済/ツリー/習い事/コレクション/**物語**/相談 内蔵済み）
- 📱SNS＝タイムライン/ファンレター＋**シェアを統合**
- ⋯メニュー（ヘッダー）＝設定・シェア・ヘルプ・デバッグ（スタレ式＝軽い機能は軽い表示）
- コメント欄横の浮きモールボタン→撤去（島タブ2タップで足りる）
- **解放の見せ場は維持**：未解放タブは🔒アイコン+タップで条件ポップ（既存lockedItemの
  文言流用）。ハブ内の🔒/？？？行もそのまま＝「先の楽しみ」提示は減らさない。
- タブバーは**ホーム画面のみ**（他画面は従来の←戻る。全画面常設は誤タップと実装リスク大）。

## 4. 表示のルール化（ウマ娘方式）
- 金色＝メインコマンドだけ（レースCTA・タブ中央）。ロック＝🔒+条件明示 or ？？？の2表現のみ。
- チップ/ピル＝状態表示（目標・ミッション・LIVE）、ボタン＝遷移。角丸・余白・字級を統一。
- 新着バッジ＝タブ右上の赤点（SNS未読・暮らし還流toast由来など・表示専用）。

## 5. 実装ウェーブ（モック承認後）
- **H-M0 モック**：CODEXへ発注（docs/CODEX_HOME_MOCK_BRIEF.md）→ユーザー確認→方向確定
- **H1 タブバー**：5タブ固定フッター＋ナビグリッド撤去＋⋯メニュー拡張＋浮きモール撤去
- **H2 ヒーロー整理**：ミッション帯をコメント上ピルへ統合・チップ群の整列
- **H3 磨き**：新着バッジ・タブのマイクロインタラクション（押下バウンス）・検証（縦/横/PC）
全て表示専用・レース数値不変。ナビ10枠固定の旧設計は本書で置き換え（解放提示は維持）。
